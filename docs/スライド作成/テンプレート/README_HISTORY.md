### 2026-09-12 — 🔴🔴 `.nb`（分割禁止）が、追加以来ずっと効いていなかった

**発端**: 大光電気工業向け提案の Phase 8-3。`fit` は0件なのに、画像で「表示され／ません」「電車線路設／備」など**泣き別れが8件**あった。
2026/8/25 に追加した `<span class="nb">` を当てても**まったく変わらなかった**。

🔴 **原因は詳細度ではない。`white-space: nowrap` だけでは、日本語の文字間の改行が止まらなかった。**

| 検証（同一ページに3行並べて描画） | 結果 |
|---|---|
| A `<span class="nb">`（`white-space: nowrap`） | ❌ 割れる |
| B `<span style="white-space:nowrap">`（**インライン＝最強の詳細度**） | ❌ 割れる |
| C `<span style="white-space:nowrap; text-wrap:nowrap; word-break:keep-all">` | ✅ 割れない |

**B が効かないので、詳細度の問題ではない。** `slide.css` の `.slide, .slide * { text-wrap: pretty }` と併用したとき、
`white-space: nowrap` は CJK の文字間の改行機会を閉じてくれない。**`word-break: keep-all` を足して初めて閉じる。**

| ファイル | 変更 |
|---|---|
| `components.css` | `.nb` を **`.slide .nb, .nb { white-space: nowrap; text-wrap: nowrap; word-break: keep-all; }`** に変更 |

⚠️ **影響範囲は 2026/8/25 以降のすべての資料。** `.nb` を書いたのに日付・金額・語が割れていた箇所は、本修正で直る。
🔴 **`fit` では原理的に出ない**（箱からはみ出していないため）。**画像を目で見る工程（Phase 8-3 の③）を省くと、永久に見つからない類**である。

### 2026-08-30 — 🔴🔴 `sample_deck.html` への検査が、CSSを読まずに通っていた

**発端**: 講義資料の Phase 8-3 で `.big-num` が**常に約21pxはみ出す**ことが判明した。
`line-height: 1` が字形の高さに足りず、**内容にかかわらず**（"640" でも "1983" でも）発生する。

🔴 **なぜ 2026/8/25 の総点検で見つからなかったか。**

`検査スクリプト/hyoji_check.py` は、**対象HTMLと同じフォルダの `css/` を作業フォルダへコピーする**実装である。
ところが **`samples/` に `css/` は無い**（CSSは1つ上の `../css/`）。
したがって **`sample_deck.html` は CSS が当たらない状態で描画され、はみ出しは原理的に検出できない。**

→ 本READMEの「今後テンプレートを変えたら `fit` を `sample_deck.html` に当てて確認する」は、**そのままでは機能しない。**

⚠️ **正しい確認のしかた**: `samples/sample_deck.html` を、`css/` を同階層に持つ作業フォルダへ複製してから `fit` を当てる。
または最小の再現HTMLを作って当てる（今回はこちらで特定した）。

| ファイル | 変更 | 理由 |
|---|---|---|
| `components.css` | `.big-num` の `line-height` **1 → 1.35** | 🔴 `--fs-huge: 128px` の字形が `line-height: 1` の行ボックスに収まらず、**内容によらず約21pxはみ出していた**。1.35 で 0件になることを実測して決めた |

⚠️ **T-05（数値ハイライト）を使う資料はすべて影響を受けていた。** 数値が大きいほど目立つ位置にあるため、影響は小さくない。

### 2026-08-25（2回目）— 改行位置の不具合。**機械では出ない類**

**発端**: GoodOld 第4版の Phase 8-3。③の転記を**原稿を知らないサブエージェント**に任せたところ、
`fit` も `diff` も0件のまま通っていた**改行の崩れ**を報告してきた。

| ファイル | 変更 | 理由 |
|---|---|---|
| `slide.css` | `.slide, .slide * { text-wrap: pretty }` | **1文字だけの行（泣き別れ）を防ぐ。** 日本語の禁則処理は「行頭に句読点を置かない」までしか面倒を見ず、**最終行が1文字になるのは防がない**。実例: 「配布・公開しなかったも／**の**」、見出し2行目が「**す**」1文字 |
| `components.css` | `.nb { white-space: nowrap }` | **日付・時刻・金額を途中で折らない。** 実例: 「2026年12月15**／日** 17:00」。使うときは `<span class="nb">2026年12月15日</span>` のように囲む |

⚠️ どちらも**未対応の環境では無視されるだけ**で、崩れは起きない。
🔴 **文字は1字も欠けていないため、`fit` にも `diff` にも出ない。画像を見て初めて分かる類である。**

**発端**: 納品直前の資料で文字が隠れていた。`検査スクリプト/hyoji_check.py fit` で**16件**のはみ出しを検出。
