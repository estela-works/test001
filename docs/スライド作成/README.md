## 一言でいうと

> **スライドプレゼンテーションとは、相手との逐次対話である。**
> 1枚のスライドは、その瞬間に相手に生じる**1つの疑問・感情を解凍する1手**であり、
> その連なりが、相手を**現在の認識から理想の認識へ移動させる**。

したがって作る順序は「情報を並べる」ではなく、**相手を想定 → 事実を整理 → ゴールを決める → ストーリーを作る → 設計表に落とす**。

🔴 **タイトルとメッセージを先に固める。**
Phase 4 で全スライドの**タイトル（事柄の名前）とメッセージ（主張）**を決め、Phase 5 で**コンテンツとテンプレート**を決める。
枚数は**持ち時間から先に決める**（上限18枚）。作りながら増やさない。
🔴 **前段のスライドをそのまま使うのは厳禁**（流用すると「要約1枚＋補足」になり、ストーリーにならない）。
**枚数は成果ではない。8枚で相手が動くなら8枚が正解。**

## 起動のしかた（本人 → AI）

**本人が言うのはこれだけでよい。**

> 「**◯◯社への提案資料を作りたい。素材はこれ**」＋ 素材（議事録・メール・既存資料など）

**AIが最初に返すもの（これ以外を先に作らない）**

1. `00_インテーク.md` の**埋まった分と、埋まらない分の質問リスト**（🔴 **まとめて1回で聞く。小出しにしない**）
2. 素材から読み取った**認識層の仮判定と、その根拠になった相手の言葉**
3. 現時点で**足りない事実**（本人に聞くもの／AIが調べるもの に仕分け済み）

素材が無い場合も止まらない。相手の公開情報（HP・求人・IR）で Phase 1 は埋められる。
ただし **Phase 2（事実）は埋められないため、作れるのは型E（関係構築型）だけ**と割り切る。

## 使い方（最短手順）

1. `ワークシート雛形/` を作業フォルダへコピーする（保管先は `プロジェクト/<案件>/提案_<相手先>_<日付>/`）
2. `00_インテーク.md` を埋める（**目的が1文で書けるまで先へ進まない**）
3. `内容検討ガイド.md` に沿って `01` → `05` を順に埋める
   - 🔴 `02_ファクト.md` で**社外に出してよいかの線引き**を先に済ませる（作ってから消すと構成ごと崩れる）
   - `04_ストーリー.md` は**タイトルとメッセージの通し表**。ゲート1（目次）とゲート2（話）の両方に通す
4. 🔴 `05_設計表.md` を本人レビューに出す（**確認してほしい点を3つ以内に絞って出す**）
5. 承認後に制作 → `品質チェックリスト.md` で検査（A〜G）
5-2. 🔴 **内容を凍結し、`業務フロー.md` Phase 8-2「言葉遣いの最終見直し」を独立して通す**（機械検査＋音読）
6. 🔴 **送付・提示は本人が実行する**（外部操作のためAIは行わない）
7. 実施後、**`06_実施記録.md` を商談直後に書く**（翌日には思い出せない）。還元先にチェックが付くまで未完了。あわせて下記「作成した資料の索引」へ1行追記
