## 事実・分析・主張（三層分離）

| # | 内容 | 層 | 出典 | 確度 |
|---|---|---|---|---|
| F1 | | 事実 | | 高 |
| F2 | | 事実 | | |
| A1 | | 分析 | F1 | |
| C1 | | 主張 | A1 | |

- **層**: 事実（F）＝検証可能／分析（A）＝事実から言えること／主張（C）＝当社の意見
- **確度**: 高＝一次資料あり／中＝推定・一般値／低＝未確認（**本編に載せない**）
- 🔴 **確度を超えた断定をしない。** 中は「〜と見込まれます」まで

## 🔴 社外に出してよいかの線引き（作る前に済ませる）

| 項目 | 確認 |
|---|---|
| 他社（既存顧客）の情報 | ☐ 顧客名・システム名・案件固有の内容を出していない（「大手SIer向け」「通信キャリア領域」までの抽象度） |
