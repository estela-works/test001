## 4. 🔴 タイトルとメッセージの通し

| | 何を書くか | 形 |
|---|---|---|
| **タイトル** | **そのスライドが何について書いてあるか。事実・事柄の名前** | 体言中心・25文字目安・1行 |
| **メッセージ** | **そのスライドで、聞き手に理解してほしいこと。主張** | 文。1〜2文。敬体 |

🔴 **両者は一致してはいけない。** タイトルは「何の話か」、メッセージは「何を理解してほしいか」。

| # | タイトル（何についての1枚か） | メッセージ（理解してほしいこと） |
|---|---|---|
| 1 | 〈資料名〉 | （表紙） |
| 2 | エグゼクティブサマリー | |
| 3 | | |
| 4 | | |
| 5 | | |

| A2 | | |

### 書くときの注意

- **同じ形の連続する数枚は、タイトルの形を揃える**（例:「◯◯の担当範囲の変化」を3枚）。**同型の並びであることが、目次だけで分かる**
- **メッセージの文型も、その並びの中で揃える**（例:「AからBになります」を3回）
- 🔴 **1枚に2つのメッセージを載せない。** 載りそうになったら、それは2枚である

## 6. 🔴 ゲート（両方に通ること）

### ゲート1（目次）— タイトル列だけを上から読む

> 〈ここにタイトルを → でつないで書き写す〉

- [ ] **何を説明する資料かが分かる**

### ゲート2（話）— メッセージ列だけを上から読む

> 〈ここにメッセージを → でつないで書き写す〉

- [ ] **1本の話として通る**

⚠️ **片方だけ通っても不合格。**
ゲート1だけなら**主張のない箱の羅列**、ゲート2だけなら**目次の作れない資料**である。

### 判定4項目（Phase 1 の相手モデルでシミュレートする）

- [ ] ① コアの問いに答えているか
- [ ] ② 各枚を見た相手が次に抱く問いが、資料内のどこかで解けているか（Appendix含む）
- [ ] ③ 懸念8類型のうち、この相手に効くものが解けているか（該当なしと判断したものは記録する）
- [ ] ④ 通しで見て、Phase 3 の After 認識に到達するか

### 通らない場合の戻り先（🔴 枚数を増やして解決しない）

| 症状 | 戻り先 |
|---|---|
| 論点が多すぎて収まらない | **1章のコアの問いへ戻り、資料を分割する** |
| 根拠が薄くて納得に届かない | **Phase 2 へ戻る** |
| 相手の認識を動かしきれない | **Phase 3 へ戻り、ゴールを分割する** |
