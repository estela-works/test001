## 🔴🔴 営業資料の大前提（2026/8/24 追加・最上位）

**顧客へ持っていく資料を作る前に、`営業資料の大前提.md` を必ず読む。** ドクトリンより前に来る前提。

- **「予定がない」は見送りの理由ではなく、提案の起点である。** 予定が無いなら、こちらが提案を作って持っていく
- 🔴 **面識のない相手へ一方的に送る場合だけの例外**は `内容検討ガイド.md` 0-2（2026/9/12 追加）。**聞かずに刺す。業界を想定しきって言い切る。門外漢の手紙は無視される**
- 提案は **事業 → 当社の役割 → 制度** の順で組み立てる（制度や自社商品から逆算しない）
- **当社が引き受ける範囲が書かれていない資料は、営業資料ではない**
- 発端: 2026/8/24、結論が「予定が無いなら出さないほうが得です」となり、「何しに来たのか」という資料になっていた

## 🔴 言葉遣い（2026/8/24 追加）

**本フォルダは資料の「内容」を担当し、「言葉遣い」は担当しない。**
社外へ出す資料を書くときは、**必ず `スペック/システム/ビジネス文書作法/文体規範.md` に従う。**

- 🔴 **見直しは工程として独立させる**（`業務フロー.md` Phase 8-2）。内容を考えながらでは、言葉は直せない
- スライド固有の論点（貴社／御社、体言止め、句読点、タイトルの文体）は `ビジネス文書作法/05_提案資料・スライドの文体.md`
- 🔴 **資料本文に「御社」と書かない（書き言葉は「貴社」）。自称は社外向けなら「弊社」**
- 発端: 2026/8/24、口語表現（「取りに行く」「出さないほうが得です」「50万円が乗る」）で指摘を受けた
