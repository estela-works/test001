## 0. この文書の位置づけ

**「どう作るか」の前に、「そもそもスライドとは何か」を固定する文書。**
テンプレートの選定基準も、レビュー基準も、AIへの指示も、すべてここから導出する。
ここが揺れると、以降の全工程が「見栄えの議論」に落ちる。

## 0-2. 🔴 本書より前に読むもの

**顧客へ持っていく資料の場合、`営業資料の大前提.md` が本書より上位に来る。**
本書は「スライドとは何か」を定義するが、その前に「**何のために相手のところへ行くのか**」が決まっていなければならない。

- 「予定がない」は見送りの理由ではなく、**提案の起点**である
- **当社が引き受ける範囲が書かれていない資料は、営業資料ではない**

## 1. 定義 — スライドプレゼンテーションとは何か

> **スライドプレゼンテーションとは、相手との逐次対話である。**
> 1枚のスライドは、その瞬間に相手の中に生じる**1つの疑問・感情を解凍するための1手**であり、
> その連なりによって、相手を**現在の認識から、理想の認識・心理状態へ移動させる**装置である。

この定義から、次が直ちに従う。

| 従うこと | 意味 |
|---|---|
| **資料の目的は「情報を渡すこと」ではない** | 目的は相手の**認識の移動**。情報は移動のための燃料にすぎない |
| **完成の判定基準は「網羅性」ではない** | 「言うべきことを全部言えたか」ではなく「**相手がそこに到達したか**」 |
| **良し悪しは相手の中でしか決まらない** | きれいな資料 ≠ 良い資料。相手が動かなければ0点 |
| **順序が本体である** | 同じ事実でも、並べ方で結論が変わる。**構成こそが成果物** |

## 2. 中核原則（8つ）

### 原則1: 1スライド = 1つの問いの解凍（1 Slide, 1 Question, 1 Message）

スライドは「トピックの箱」ではない。**相手の問いに対する1つの答え**である。

🔴 **見出しは2段で書く**（2026-08-30 改定）

| | 何を書くか | 例 |
|---|---|---|
| **タイトル**（上段） | **そのスライドが何について書いてあるか。事実・事柄の名前。** 体言中心で短く | 「メンバーの担当範囲の変化」 |
| **メッセージライン**（下段） | **理解してほしいこと。主張。** 文で書く | 「メンバーは、機能を作る人から、案件1本の責任を持つ人になります」 |

- 🔴 **両方をメッセージにしない。** タイトルまで主張にすると、**そのスライドが何の話かを示す場所が無くなり、目次が作れない**
- 🔴 **両方をトピック名にしない。** メッセージラインが無ければ、資料は主張を持たない箱の羅列になる
- **1枚に2つのメッセージを載せない。** 載りそうになったら、それは2枚である
- **通読テストは2つある。両方に通ること**
  - **ゲート1（目次）**: タイトルだけを上から読んで、**何を説明する資料かが分かる**
  - **ゲート2（話）**: メッセージラインだけを上から読んで、**1本の話として通る**

⚠️ **改定の経緯**: 2026/8/30、**「タイトルとは内容の要約であり、説明する事実や事柄を示す。現状はどちらもメッセージになっている」**との指摘による。
旧原則は「タイトルは**トピック名ではなくメッセージ**で書く（❌ 現状分析 → ⭕ 属人化はすでに事業リスクの水準に達しています）」だった。
これは**タイトルとメッセージを同じものにしてしまい、そのスライドが何の話かを示す場所を資料から奪っていた。**

### 原則2: 並べる順序は「論理順」ではなく「心理順」

論理的に正しい順序と、相手が納得する順序は一致しない。

- 相手はスライド i を見た瞬間、必ず次の問いを抱く（「なぜ？」「本当に？」「うちでも？」「いくら？」）
- **その問いこそが次のスライドである**（＝問いの連鎖 / Question Chain）
- 連鎖が切れた瞬間、相手の思考は資料から離れる。以降のページは物理的に見えていても読まれていない

### 原則3: 懸念は伏せず、相手が言う前にこちらから出す

相手が反論・不安を抱えたまま先に進むと、**それ以降のスライドはすべて素通りされる**。

- 想定される懸念は、必ずストーリーのどこかで**明示的に扱う**
- 先に自分から出すほうが信頼される（隠していないという証明になる）
- 弱点を出したうえで「それでも成立する理由」を示すのが、最も強い説得になる

### 原則4: ゴールは「こちらの結論」ではなく「相手の理想的な心理状態」

ゴールを「提案を採用してもらう」と書いた時点で設計は失敗している。書くべきはこう。

> 相手が **◯◯を自分の課題として認識**し、**◯◯という不安が解消**され、
> **◯◯を自分の言葉で社内に説明できる**状態になっている。

- 特に「**自分の言葉で他人に説明できる**」は重要。日本企業では、聞き手はほぼ必ず社内の別の誰かに説明する
- したがって**資料は相手の武器になる**必要がある

### 原則5: ストーリーを作ることは、事実を都合よく編集することではない

🔴 **ここが最も踏み外しやすい一線。**

- ストーリー設計とは、事実に対する **「順序・強調・翻訳」の設計**である
- **事実そのもの（数値・出典・前提条件）は改変しない。** 不確実なものは不確実と書く
- 都合の悪い事実を落とすのは「編集」ではなく「隠蔽」であり、一度でもやると次の商談を失う
- 根拠: 価値基準③実効性「**見栄えだけ良い提案をするか**」／ミッション「難しいことを、わかりやすく」（＝**わかりやすく歪める**ではない）
- 手順としての担保 → `内容検討ガイド.md` Phase 2「事実・分析・主張の三層分離」

### 原則6: 話すことと、書くことを分ける

スライドに話す内容を全部書くと、相手は読み始め、こちらの話を聞かなくなる。

- **スライド本文** = 結論と根拠の骨格（相手が後で見返して意味が通る最小限）
- **スピーカーノート** = 口頭で肉付けする内容、想定問答
- **Appendix** = 聞かれたら出す根拠・詳細データ（本編には入れない）

### 原則7: 資料は本人不在で社内を歩く

対話用として最適化しすぎると、配布された瞬間に意味不明になる。この二律背反は次で処理する。

- 本編は**対話用**に設計する（枚数を絞り、問いの連鎖で進む）
- **一人歩き対策**は、①**メッセージラインをスライド上に載せる**（原則1）②要約1枚を冒頭に置く ③Appendixで根拠を担保 の3点で行う
- 「送付用」と「対面用」をファイルごと分けるのは、必要になってから

### 原則8: 難しいことを、わかりやすく（＝相手の語彙に翻訳する）

会社のミッションそのものであり、当社の資料の**差別化要因**でもある。

- 専門用語は、相手の業務語彙に置き換える。置き換えられないものは1行で定義する
- 図は装飾ではない。**文章より速く理解できるときだけ**使う
- 相手がその場で理解できない資料は、内容が正しくても価値が0

## 3. アンチパターン（これをやったら作り直し）

| アンチパターン | なぜダメか |
|---|---|
| 素材資料の順番のまま並べる | それは「相手の心理順」ではなく「こちらの都合順」 |
| 1枚に情報を詰め込む | 1枚1メッセージが崩れ、相手はどこを見ればいいか分からなくなる |
| 🔴 タイトルとメッセージが**両方とも主張**になっている | そのスライドが**何の話か**を示す場所が無くなり、**目次が作れない**（→ 原則1） |
| メッセージラインが無く、**トピック名だけ**で並んでいる | 資料が主張を持たず、一人歩きに耐えない（→ 原則1） |
| 事実と解釈を同じ強さで書く | 相手が検証できず、1点崩れると全部の信用を失う |
| 懸念を書かない／末尾に小さく書く | 相手はその懸念を抱えたまま最後まで聞き、結局決めない |
| きれいな図から作り始める | 構成が固まる前の作図は、ほぼ全部捨てることになる |
| 選択肢を並べて「ご検討ください」で終わる | 相手に宿題を渡す行為。推奨と理由を必ず添える |
| 枚数が持ち時間に対して多すぎる | 逐次対話が成立せず「説明会」になる。認識は動かない |

## 4. 役割分担（誰が何をやるか）

| 工程 | AI（秘書） | 本人（社長） |
|---|---|---|
| ①相手の想定 | 業界・企業の調査、懸念の洗い出し案 | **相手の実像・温度感の補正**（面談で得た情報はAIが持っていない） |
| ②事実の整理 | 素材からの抽出、出典・確度付け、不足の指摘 | 不足事実の提供 |
| ③ゴール定義 | 案の作成 | 🔴 **確定**（何を勝ちとするかは経営判断） |
| ④ストーリー構築 | 構築・ループ・収束 | — |
| ⑤スライド分割 | 設計表の作成 | 🔴 **レビューと承認** |
| ⑥⑦制作 | 実作業 | — |
| ⑧品質チェック | チェックリスト実行 | 最終確認 |
| ⑨納品 | 出力ファイル準備まで | 🔴 **送付・提示（外部操作は本人）** |

> 目指す状態は、他業務と同じく「**本人に残るのは意思決定だけ**」。
> ③のゴール確定と⑤の骨子承認以外で、本人の手を止めない。
