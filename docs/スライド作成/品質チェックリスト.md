## A. 骨子（→ NGなら Phase 4〜5 に戻る）

- [ ] 🔴 **ゲート1（目次）**: **タイトル**だけを上から読んで、**何を説明する資料かが分かる**
- [ ] 🔴 **ゲート2（話）**: **メッセージライン**だけを上から読んで、1本のストーリーとして通る
- [ ] **問いの連鎖**: 各ページの後に相手が抱く問いが、次のページで扱われている
- [ ] **1枚1メッセージ**: 2つ以上を主張しているページがない
- [ ] 🔴 **見出しが2段になっている**: タイトル（事柄の名前）とメッセージライン（主張）が、どのスライドにも両方ある
- [ ] 🔴 **両方が主張になっていない**: タイトルが「〜します」「〜です」の主張文になっていないか（→ ドクトリン原則1）
- [ ] **メッセージラインが「文」になっている**（体言止めのトピック名で終わっていない）
- [ ] **ゴール到達**: 通しで読むと、Phase 3 の After 認識に到達する
- [ ] **不要な枝がない**: どのページも、削ると After に到達できなくなる
- [ ] 🔴 **枚数が Phase 4 で決めたとおり**（設計・制作の途中で増やしていない）
- [ ] 🔴 **前段の流用がない**: 採用した段が、下の段のスライドを貼り付けた継ぎ足しになっていない
- [ ] **上限内**: 18枚以内、かつ持ち時間から決まる実効上限以内

## E-0. 🔴 言葉遣い（**Phase 8-2 の独立パスで検査する**／NGなら `スペック/システム/ビジネス文書作法/文体規範.md` に戻る）

> 🔴 **この区分だけは、他の区分と一緒に見ない。** 内容（A〜F）を凍結したうえで、**言葉だけを見るパスをもう1回通す**。
> 手順・機械検査コマンド・言い換えの原則は `業務フロー.md` Phase 8-2。
> 発端: 2026/8/24。規範を作った直後の版でも、**内容を考えながら書いた身内の言葉**（提案して入る／業態／商談導線／採算）が入り込んだ。

- [ ] **敬体（です・ます）で統一されている**（常体が混じっていない）
- [ ] **話し言葉が1つもない**（`ビジネス文書作法/04_言い換え辞書.md` §2の禁止語を検索した）
- [ ] 🔴 **本文に「御社」と書いていない**（書き言葉は「貴社」）
- [ ] **自称が「弊社」で統一されている**（社外向けの場合。中立文書は「当社」）
- [ ] **二重敬語・過剰敬語がない**（拝見させていただく／ご覧になられる／貴社様）
- [ ] **「させていただく」が「許可＋恩恵」の2条件を満たしている**
- [ ] 🔴 **損得・比喩・煽りの表現がない**（得です／乗る／取りに行く／逃すと）
- [ ] **確度を超えた断定がない**（必ず／絶対／確実／保証 を検索した）
- [ ] **試算に「弊社の試算であり見積ではない」旨が併記されている**
- [ ] **タイトルに句点が付いていない／箇条書きの止め方が統一されている**
- [ ] 🔴 **身内の言葉がない**（社内の議論で使っていた略語をそのまま載せていない。例: 商談導線／採算／チャネル／業態）
- [ ] 🔴 **主語が曖昧な文がない**（「◯◯します」の主語が貴社か弊社か、文だけで分かる）
- [ ] **通しで音読した**（機械検査に掛からない不自然さは、これでしか見つからない）
- [ ] 🔴 **見つかった誤りを `04_言い換え辞書.md` と `指摘ログ.md` へ還元した**（資料だけ直して終わりにしていない）

## 検査の順序

**A〜G を先に通し、そのあとで E-0 を単独で通す。** 内容を直すと言葉も変わるため、順序を逆にすると二度手間になる。

```
A-0 営業資料の大前提（何のために行くか）
  → A 骨子 → B 事実 → B-2 社外可否 → C 相手 → D 一人歩き → D-2 テンプレ規約 → E わかりやすさ → F 時間 → G 体裁
      → 【内容を凍結】
        → E-0 言葉遣い（Phase 8-2・独立パス）
          → Phase 9 納品
```
