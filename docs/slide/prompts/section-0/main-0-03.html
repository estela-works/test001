インターネットネイティブの最適化対象変化
配信制約が消えると価値は届ける力から見つかる力へ移る
不変の目的: 広く情報を届ける
旧

コスト構造

配信や複製のコストが高く、届けられる枠そのものが希少だった。

最適化対象

限られた配信チャネルをどう押さえるかが勝負だった。

支配的な戦略

出版社、放送局、流通網などゲートキーパーを通ること。

新

コスト構造

配信コストはほぼゼロになり、誰でも公開できる状態が前提に。

最適化対象

大量の情報の中で、どう発見されるかが中心課題に。

支配的な戦略

検索、推薦、レビュー、共有導線の設計が価値を左右する。

脱構築
出版社や放送局の独占、紙の目録、物理メディア前提の流通網
再構築
検索、SEO、レコメンド、レビュー、発見を支えるプラットフォーム
