# WebRelease2 承認ワークフロー・ユーザー管理・配信管理

## ユーザー管理

### ユーザー種別

| 種別 | 説明 |
|------|------|
| システム管理者 | WebReleaseのすべての機能を使用可能 |
| 一般ユーザー | 割り当てられた権限に応じた操作のみ可能 |

### ユーザー管理機能

- ユーザー登録（CSV一括登録対応）
- パスワード管理
  - 有効期限設定
  - 文字種制約（複雑さの要件）
  - 再利用禁止
- ユーザープロファイル設定
- アカウント有効期限設定
- ユーザーの休止・削除
- セッションタイムアウト設定（10分～1,500分）
- ログインユーザー一覧表示
- ログイン履歴管理

## スタッフの役割（ロール）

サイトごとにスタッフを任命し、役割を割り当てる。

| 役割 | 説明 |
|------|------|
| **ライター** | ページの作成・編集を担当 |
| **エディター** | ページの編集・レビューを担当 |
| **デザイナー** | テンプレートの作成・編集を担当 |
| **マネージャー** | サイト管理・承認プロセスの定義等を担当 |

- 一括設定が可能
- 会社のセクションごとにワークフローを構築可能

## 承認ワークフロー

### 概要

- **最大5段階**の承認プロセスを定義可能
- 承認プロセスはいくつでも作成可能
- 各ステップに自由に承認担当者を配置
- フォルダ単位で承認プロセスを指定可能
- 承認プロセスの定義にはマネージャー権限が必要

### 承認フロー

```
[ライター] ページ編集完了
    ↓ 承認依頼
[承認者 ステップ1] 承認 or 差戻
    ↓ 承認
[承認者 ステップ2] 承認 or 差戻  ※最大5段階
    ↓ 承認
    ...
    ↓ 最終承認
[公開] FTP/SFTPで公開サーバへ配信
```

### 承認機能の詳細

| 機能 | 説明 |
|------|------|
| 承認依頼 | ページ編集完了後に承認者へ依頼 |
| 一括承認依頼 | 複数ページをまとめて承認依頼 |
| 承認 | 承認者がページを承認 |
| 差戻 | 承認者がページを差し戻し |
| 一括承認 | 複数ページをまとめて承認 |
| 承認依頼フォルダ | 承認依頼をフォルダで管理 |
| 承認依頼の削除 | 不要な承認依頼を削除 |

### 通知メール

プロセスの進行に伴い、以下の通知メールが自動送信される。

| メール種別 | タイミング |
|---|---|
| 承認依頼メール | 承認依頼時 |
| 承認完了メール | 承認完了時 |
| 差戻通知メール | 差戻時 |
| 承認遅延警告メール | 承認が遅延している場合 |

### 承認プロセスとページの公開終了

承認プロセスはページの公開終了にも適用可能。

## コンテンツ配信管理

### 配信方式

WebRelease2は静的CMSのため、CMSサーバで生成したHTMLを公開サーバへ配信する。

| 配信プロトコル | 認証方式 |
|---|---|
| FTP | パスワード認証 |
| SFTP | パスワード認証 / 公開鍵認証 |
| Amazon S3 | S3直接配信 |

### 配信モード（4種類）

| モード | 説明 |
|---|---|
| **AUTO** | ページの公開開始/終了時刻に合わせて自動的にFTP起動 |
| **SCHEDULED** | 定時起動（毎日一定時刻、曜日制限可能） |
| **MANUAL** | 手動でFTPを起動 |
| **OFF** | FTPを無効化 |

### スケジュール配信

- ページに「公開開始指定時刻」が設定されている場合、その時刻到来時に自動的にFTPが起動
- 将来のある時刻に1度だけ起動する指定が可能
- 毎日一定時刻に起動する指定が可能（起動する曜日の制限も可能）

### 差分配信

- 既存コンテンツの変更や新規コンテンツの追加時は、差分のみが転送される
- 「全コンテンツをアップロードする」チェックボックスで全コンテンツ再アップロードも可能

### 配信管理機能

| 機能 | 説明 |
|------|------|
| 配信予約 | 繰り返し設定対応 |
| 配信ログ | FTP実行状況と記録の参照 |
| URL衝突検出 | URLの重複を検出 |
| 並列処理 | 配信の並列実行 |
| エラー通知メール | 配信エラー時にメール通知 |
| 公開スケジュール一覧 | スケジュールされた公開予定の一覧表示 |
