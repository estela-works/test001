# WebRelease2 テンプレート仕様

## テンプレートの基本概念

WebRelease2では、すべてのページはテンプレートから生成される。テンプレートは以下の要素で構成される。

```
テンプレート
├── 文書型定義（要素の組み合わせ）
├── 展開（HTMLマークアップ + 式 + 拡張タグ）
├── メソッド（再利用可能な処理）
└── リソース（テンプレート固有のファイル）
```

---

## 要素タイプ一覧（15種類）

テンプレートの文書型定義で使用する要素タイプ。

| # | タイプ | 用途 | 戻り値 |
|---|--------|------|--------|
| 1 | **１行テキスト** | 氏名、電話番号、住所など短いテキスト | 入力文字列 |
| 2 | **複数行テキスト** | 記事本文など長いテキスト | 入力文字列 |
| 3 | **WYSIWYGエディタ** | リッチテキスト編集（画像挿入・添付ファイル対応） | HTML文字列 |
| 4 | **ラジオボタン** | 複数選択肢から1つを選択 | 選択肢文字列 |
| 5 | **ポップアップボタン** | ラジオボタンと同様だがポップアップ形式 | 選択肢文字列 |
| 6 | **チェックボックス** | 複数選択肢から複数を選択 | CheckBoxオブジェクト |
| 7 | **年月日/時分/秒** | 日付・時刻（5形式対応） | 1970/1/1 0:0:0 GMTからのミリ秒数 |
| 8 | **目次** | 新着情報などのリンク集 | Pageオブジェクト配列 |
| 9 | **リンク** | サイト内ページへのリンク | リンク先ページのURL |
| 10 | **イメージ** | GIF, PNG, JPG, WebP, BMP画像 | イメージのURL |
| 11 | **添付ファイル** | PDF、Flash、Office文書等 | 添付ファイルのURL |
| 12 | **XMLリーダ** | RSSフィード等のXMLデータをHTTP経由で取り込み | XMLReaderオブジェクト |
| 13 | **コンポーネント** | 他テンプレート/コンポーネントの埋め込み | N/A（直接参照不可） |
| 14 | **グループ項目** | 複数要素を束ねた複合構造（住所、氏名等） | N/A（直接参照不可） |
| 15 | **セレクタ** | 複数子要素のうち1つのみ選択入力 | Selectorオブジェクト |

### 年月日/時分/秒の5形式

| 形式 | 入力内容 |
|------|----------|
| 年 | 年のみ |
| 年月 | 年と月 |
| 年月日 | 年月日 |
| 年月日時分 | 年月日と時分 |
| 年月日時分秒 | 年月日と時分秒 |

### 要素の共通属性

- 入力可能文字数制限
- 繰り返し設定（配列化）
- 必須設定
- デフォルト値

## 展開（テンプレートの出力部分）

展開はテンプレートの出力を定義する部分。HTML + 式（`%...%`）+ 拡張タグで構成される。

### 式の基本構文

```html
<!-- 要素値の参照 -->
%要素名%

<!-- グループ項目の参照（ドット記法） -->
%住所.郵便番号%
%住所.氏名.名%

<!-- 配列の参照（ブラケット記法、0始まり） -->
%要素名[0]%
%住所[0].郵便番号%
```

### HTML処理（エスケープ）

テキスト系要素には「HTML可」オプションがある。

| 設定 | 動作 |
|------|------|
| HTML可 = OFF | `<`, `>`, `&` を `&lt;`, `&gt;`, `&amp;` に変換（既存文字参照は変換しない） |
| HTML可 = ON | 入力テキストをそのまま出力 |

## コンポーネント

頻出する文書構造をモジュール化して再利用する仕組み。

- テンプレートとほぼ同じ機能を持つ
- テンプレートや他のコンポーネントに埋め込み可能
- 文書型定義・展開・メソッドを持つ
- 部品化により、テンプレート作成の効率化が可能

---

## メソッド

テンプレートやコンポーネント内で定義する再利用可能な処理。

- パラメータ付きのメソッド定義が可能
- テンプレートの展開内から呼び出し可能
- 再帰呼び出しにも対応

---

## テンプレート管理機能

### リビジョン管理

- テンプレートの編集履歴をリビジョンとして保持
- リビジョン作成時点の状態が保存され、編集不可の状態で保管
- 新しいリビジョンが自動作成され、以降の編集対象となる

### テンプレートフォルダ

- テンプレートをフォルダで階層管理可能

### テンプレートプロファイラ

- テンプレートの展開処理のパフォーマンス計測機能

### その他

- 複数文字コード対応
- 出力フィルタ
- 100以上の組み込み関数
- 拡張タグによる制御構文
