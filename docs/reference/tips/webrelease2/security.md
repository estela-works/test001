# WebRelease2 セキュリティ・運用管理

## セキュリティ機能

### 認証・アクセス制御

| 機能 | 説明 |
|------|------|
| 2段階認証（TOTP） | ID/パスワードに加え、TOTPワンタイムパスワードの併用が可能 |
| ログイン通知メール | ログイン時にユーザーへ通知メールを送信 |
| アカウント自動閉鎖 | 一定期間未使用のアカウントを自動的に閉鎖 |
| Brute Force Attack対策 | ログイン失敗が続くと保護モードに移行 |
| セッションタイムアウト | 10分～1,500分の範囲で設定可能 |
| アカウント有効期限 | ユーザーアカウントの有効期限を設定可能 |

### パスワードセキュリティ

| 機能 | 説明 |
|------|------|
| パスワードハッシング | PBKDF2（310,000回以上のストレッチング） |
| 有効期限 | パスワードの有効期限を設定可能 |
| 文字種制約 | パスワードの複雑さ要件を設定可能 |
| 再利用禁止 | 過去のパスワードの再利用を禁止 |

### データ保護

| 機能 | 説明 |
|------|------|
| サイトの暗号化保護 | 128bit AESによる暗号化 |
| SFTP公開鍵認証 | 配信時の安全な通信 |
| STARTTLS | メール送信時の暗号化 |

### アーキテクチャによるセキュリティ

- **静的配信**: 公開サーバにCMSが存在しないため、CMS自体への攻撃が不可能
- **サーバ分離**: CMSサーバと公開サーバが分離されており、公開サーバへの攻撃がCMSに影響しない
- **データベース不要**: DB攻撃（SQLインジェクション等）のリスクがない
