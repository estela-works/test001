# WebRelease2 製品概要

## 基本情報

| 項目 | 内容 |
|------|------|
| 製品名 | WebRelease2（ウェブリリース2） |
| 開発元 | 株式会社フレームワークス・ソフトウェア |
| 種別 | エンタープライズ向け静的CMS（商用パッケージ） |
| 最新バージョン | 2.80N |
| 導入実績 | 1,000社以上（大手メーカー、金融機関、官公庁、大学等） |

## 製品の特徴

### 静的CMS

- CMSサーバでHTMLを生成し、公開サーバにFTP/SFTPで配信する方式
- 公開サーバにCMSが存在しないため、外部攻撃に対して強い
- 大量アクセスが発生してもCMSサーバに負荷がかからない
- WordPressのような動的CMSとは根本的にアーキテクチャが異なる

### エンタープライズ対応

- 数万ページ規模のサイトを1台のCMSサーバで管理可能
- 最大5段階の承認ワークフロー
- 詳細な権限管理・操作履歴
- マルチチャネル配信（PC/スマートフォン/タブレット等）

### ノンプログラミング

- テンプレートはHTMLベースで開発可能
- 拡張タグと組み込み関数で柔軟なテンプレート設計
- データベースサーバ不要（独自リポジトリエンジン搭載）

## 動作環境・システム要件

### CMSサーバ

| 項目 | 要件 |
|------|------|
| OS（Linux） | Amazon Linux 2023, 2 (x86_64/aarch64) |
| | Red Hat Enterprise Linux 8, 9, 10 (x86_64/aarch64) |
| | AlmaLinux 8, 9, 10 (x86_64/aarch64) |
| | Rocky Linux 8, 9, 10 (x86_64/aarch64) |
| | MIRACLE LINUX 8 (x86_64) |
| OS（macOS） | macOS Tahoe 26, Sequoia v15, Sonoma v14 (Intel/Apple Silicon) |
| Java | OpenJDK 17（Amazon Corretto、製品に付属） |
| アプリケーションサーバ | Tomcat 10（製品に付属） |
| HTTPサーバ | Apache 2 + mod_proxy（OS同梱） |
| ハードウェア | メモリ 2GB以上、マルチコアCPU推奨 |
| データベース | 不要（独自リポジトリエンジン搭載） |

### クライアント環境

| 項目 | 要件 |
|------|------|
| 対応ブラウザ | Microsoft Edge, Google Chrome, Mozilla Firefox, Apple Safari |
| 非対応 | IE11モード |

### その他

| 項目 | 要件 |
|------|------|
| SMTP | ポート25/465/587対応、STARTTLS・パスワード認証対応 |
| 公開Webサーバ | FTP/SFTP対応が必要、Amazon S3直接配信にも対応 |
