# WebRelease2 サイト構成

## サイトの階層構造

WebRelease2のコンテンツは以下の階層で管理される。

```
サイト（Site）
├── フォルダ（Folder）
│   ├── ページ（Page）
│   ├── ページ（Page）
│   └── サブフォルダ（Folder）
│       └── ページ（Page）
├── テンプレート（Template）
│   └── コンポーネント（Component）
├── サイトリソース（Site Resource）
└── チャネル（Channel）
```

---

## フォルダ

- ページやサブフォルダを格納する階層構造を自由に構築可能
- フォルダ階層は公開サーバ上のディレクトリ構造にマッピングできる
- 並び順は昇順・降順の他、ドラッグ＆ドロップで自由に指定可能
- フォルダにはページ新規作成時に利用可能なテンプレートを指定できる
- ページの他フォルダへの移動が可能
- フォルダ単位でアクセス制限・承認プロセスを設定可能
- ページ作成制限の設定が可能

## ページ

### ページの状態遷移

ページは6つの状態を持つ。

```
[編集中] → [編集完了] → [公開待] → [公開中] → [公開終了待] → [公開終了]
                ↑                                    |
                └────────────────────────────────────┘
```

| 状態 | 説明 |
|------|------|
| 編集中 | コンテンツを編集している段階 |
| 編集完了 | 編集が完了し承認待ちの段階 |
| 公開待 | 承認済み、公開開始時刻の到来待ち |
| 公開中 | 公開サーバにアップロードされ公開されている状態 |
| 公開終了待 | 公開終了時刻の到来待ち |
| 公開終了 | 公開が終了した状態 |

### ページの機能

- **リビジョン管理**: 編集履歴を保持し、任意のリビジョンに復旧可能
- **リビジョン比較**: 6種類の表示方法で差分を確認
- **画像加工**: リサイズ、回転
- **公開期間指定**: 公開開始・終了時刻を指定
- **語句・文字チェック**: 4種類の辞書による自動チェック
- **プレビュー**: 時刻指定対応、デバイス別表示、QRコードによるスマートフォンプレビュー
- **一括処理**: 複数ページの一括操作
- **一括ページ生成**: CSVインポートで最大10,000ページを一括生成
- **エキスポート/インポート**: ページ単位のバックアップ・復元

## チャネル（マルチデバイス配信）

1件のページ入力データから、複数デバイス向けの異なるHTMLを生成・配信する機能。

### 概要

- チャネルはいくつでも定義可能
- PC・スマートフォン・タブレット等、デバイスごとにコンテンツを出し分け可能
- チャネルごとに異なるサーバ（または同一サーバの異なるディレクトリ）に配信可能
- チャネルごとに文字コードを指定可能

### 配信先の設定

| 項目 | 設定内容 |
|------|----------|
| プロトコル | FTP / SFTP / Amazon S3 |
| SFTP認証 | パスワード認証 / 公開鍵認証 |
| mod_rewrite | デバイス判別ルールの設定が可能 |

## リソース

### サイトリソース

- サイト全体で共有するファイル（CSS、JavaScript、画像等）
- YUICompressor統合による圧縮機能
- サイト全体で利用可能

### ページリソース

- 特定のページに紐づくリソースファイル
- ページ単位で管理

### テンプレートリソース

- テンプレートに紐づくリソースファイル

### リソースフォルダ

- リソースをフォルダで階層管理可能
