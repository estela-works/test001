# WebRelease2 式・演算子・関数・オブジェクト

## 式（Expression）

テンプレートの展開内で `%...%` に囲んだ部分が式として評価される。

### 要素参照

```html
<!-- 基本 -->
%要素名%

<!-- グループ項目（ドット記法で階層参照） -->
%グループ名.子要素名%
%住所.氏名.名%

<!-- 配列（ブラケット記法、0始まり） -->
%要素名[0]%
%住所[0].郵便番号%

<!-- 関数呼び出し -->
%length(テキスト要素)%
%substring(説明, 0, 100)%
```

### 要素型ごとの戻り値

| 要素型 | 戻り値の型 |
|--------|-----------|
| 1行テキスト | 文字列 |
| 複数行テキスト | 文字列 |
| WYSIWYGエディタ | HTML文字列 |
| ラジオボタン | 文字列（選択肢） |
| ポップアップボタン | 文字列（選択肢） |
| チェックボックス | CheckBoxオブジェクト |
| 年月日/時分/秒 | 数値（1970/1/1からのミリ秒） |
| 目次 | Pageオブジェクト配列 |
| リンク | 文字列（URL） |
| イメージ | 文字列（URL） |
| 添付ファイル | 文字列（URL） |
| XMLリーダ | XMLReaderオブジェクト |
| セレクタ | Selectorオブジェクト |
| コンポーネント | エラー（直接参照不可） |
| グループ項目 | エラー（直接参照不可） |

## 演算子

### 比較演算子

| 演算子 | 機能 |
|--------|------|
| `==` | 等値判定 |
| `!=` | 非等値判定 |
| `<` | 未満 |
| `<=` | 以下 |
| `>` | 超過 |
| `>=` | 以上 |

**`==` の比較ルール**:
- 論理値同士：同じ値で真
- 数値同士：数値的に同じで真
- 文字列同士：同じ綴りで真
- 混合型：文字列を数値に変換して比較

**`>`, `>=`, `<`, `<=` のルール**:
- 論理値は比較不可
- 数値同士：数値で大小判定
- 文字列同士：字句的に比較
- 混合型：文字列を数値変換して比較

### 論理演算子

| 演算子 | 機能 |
|--------|------|
| `&&` | 論理積（AND） |
| `\|\|` | 論理和（OR） |

両辺は論理値である必要がある。

### 数値演算子

| 演算子 | 機能 |
|--------|------|
| `+` | 加算 |
| `-` | 減算 |
| `*` | 乗算 |
| `/` | 除算 |

精密な計算が必要な場合は `divide()` または `setScale()` 関数の使用を推奨。

## 組み込みオブジェクト

12種類の組み込みオブジェクトが利用可能。

| オブジェクト | 説明 |
|---|---|
| **Channel** | チャネル情報 |
| **CheckBox** | チェックボックス要素の値 |
| **Folder** | フォルダ情報 |
| **HTMLComment** | HTMLコメントノード |
| **HTMLDataNode** | HTMLデータノード |
| **HTMLDocument** | HTMLドキュメント |
| **HTMLElement** | HTML要素ノード |
| **HTMLElements** | HTML要素の集合 |
| **HTMLTextNode** | HTMLテキストノード |
| **Page** | ページ情報 |
| **Selector** | セレクタ要素の値 |
| **XMLFeed** | XMLフィード情報 |

### 主要なオブジェクト操作

#### thisPage()

現在のページのPageオブジェクトを返す。メソッド呼び出しや他の関数のパラメータとして使用可能。

```html
%thisPage()%
```

#### pageWithPageID()

指定したページIDのPageオブジェクトを返す。

```html
%pageWithPageID(12345)%
```

## 組み込み関数（主要なもの）

80種類以上の組み込み関数が利用可能。以下は主要なカテゴリ別一覧。

### 文字列操作

| 関数 | 説明 |
|------|------|
| `length(str)` | 文字列の長さを返す |
| `substring(str, start, end)` | 部分文字列を抽出 |
| `string(num)` | 数値を文字列に変換 |
| `split(str, pattern)` | 正規表現で文字列を分割 |
| `replaceAll(str, pattern, replacement)` | パターンに一致する全箇所を置換 |
| `replaceFirst(str, pattern, replacement)` | パターンに最初に一致する箇所を置換 |
| `startsWith(str, prefix)` | 指定文字列で始まるか判定 |
| `endsWith(str, suffix)` | 指定文字列で終わるか判定 |
| `concatenate(str1, str2, ...)` | 文字列連結 |
| `halfwidth(str)` | 全角→半角変換 |
| `codePointAt(str, index)` | 指定位置の文字コードを返す |

### 数値操作

| 関数 | 説明 |
|------|------|
| `number(str)` | 文字列を数値に変換 |
| `divide(a, b, scale)` | 精密な除算 |
| `setScale(num, scale)` | 小数点以下の桁数を設定 |
| `comma3(num)` | 3桁カンマ区切り |

### 日付操作

| 関数 | 説明 |
|------|------|
| `formatDate(millis, format)` | 日時をフォーマット |
| `formatDateRFC2822(millis)` | RFC2822形式でフォーマット |
| `formatDateW3CDTF(millis)` | W3C DTF形式でフォーマット |
| `currentTime()` | 現在時刻をミリ秒で返す |
| `gengou(millis)` | 和暦変換 |

### リスト操作

| 関数 | 説明 |
|------|------|
| `count(list)` | リストの要素数を返す |
| `head(list, n)` | リストの先頭n件を返す |
| `firstElement(list)` | リストの最初の要素を返す |
| `add(list, element)` | リストに要素を追加 |
| `find(list, condition)` | 条件に合う要素を検索 |

### ページ・サイト操作

| 関数 | 説明 |
|------|------|
| `thisPage()` | 現在のページオブジェクトを返す |
| `pageWithPageID(id)` | 指定IDのページを返す |
| `folder(page)` | ページが属するフォルダを返す |
| `allPages()` | 全ページの一覧を返す |
| `allObjects()` | 全オブジェクトの一覧を返す |
| `channel()` | 現在のチャネルを返す |
| `channelName()` | 現在のチャネル名を返す |
| `channelCookieName()` | チャネルのCookie名を返す |

### ファイル操作

| 関数 | 説明 |
|------|------|
| `fileName(url)` | URLからファイル名を抽出 |
| `fileSize(url)` | ファイルサイズを返す |
| `contentType(url)` | コンテンツタイプを返す |

### URL操作

| 関数 | 説明 |
|------|------|
| `fullURL(path)` | 完全なURLを返す |
| `encodeURI(str)` | URIエンコード |
| `encodeURIComponent(str)` | URIコンポーネントエンコード |
| `encoding()` | 現在の文字エンコーディングを返す |

### 判定関数

| 関数 | 説明 |
|------|------|
| `isNull(value)` | null判定 |
| `isNotNull(value)` | 非null判定 |
| `isNumber(value)` | 数値判定 |
| `hasElement(name)` | 要素の存在判定 |
| `hasMethod(name)` | メソッドの存在判定 |

### その他

| 関数 | 説明 |
|------|------|
| `group(element)` | グループ項目の参照 |
| `indexOfPage(page)` | ページのインデックスを返す |
| `height(image)` | 画像の高さを返す |
| `getXML(url)` | XMLデータを取得 |

### 関数呼び出しの構文

```html
<!-- 基本 -->
%length(テキスト要素)%

<!-- ネスト -->
%substring(説明, 1, length(説明))%

<!-- メソッド呼び出し -->
%thisPage().method名(引数)%
```

### 命名規則

要素名・リソース名・変数名・メソッド名に使用可能な文字に制限あり。文字数の制限はなし。
