## 1. dカード設定処理フロー

顧客詳細画面からdカード選択モーダルを表示するまでの処理フロー。

```
顧客詳細画面
    │
    │ ① 料SIM画面に遷移
    ▼
条件設定タブ ──────② 汎用マスタからdカードのサービスコードを取得──────→ 汎用マスタ(汎用M)
    │
    │               ③ 契約中サービスから契約中dカード（ランク）を取得する
    │                       ▲
    │                       │
    │               dカード契約有無チェック ※UI上での処理
    │
    │               ④ 初期モデルから契約中サービス一覧を取得する
    ▼                       │
dカード選択モーダル ◀────────┘───────────────────────────────→ 初期モデル(Pinia)
```

### 処理ステップ詳細

| ステップ | 処理内容 | 取得先 |
|----------|----------|--------|
| ① | 料SIM画面に遷移 | 顧客詳細画面 → 条件設定タブ |
| ② | 汎用マスタからdカードのサービスコードを取得 | 汎用マスタ（汎用M） |
| ③ | 契約中サービスから契約中dカード（ランク）を取得 | UI上での処理（dカード契約有無チェック） |
| ④ | 初期モデルから契約中サービス一覧を取得 | 初期モデル（Pinia） |
| ⑤ | 処理③で取得したdカード（ランク）をもとに表示項目を導出。dカード選択ラジオボタンは汎用マスタの内容をもとに動的に表示する | ②と③の結果を組み合わせ |

## 2. dカード選択UI仕様

### 表示タイトル

「月額支払いに利用するdカード」

### ラジオボタン選択肢

| 選択肢 | 説明 |
|--------|------|
| dカード PLATINUM | 最上位ランク |
| dカード GOLD | ゴールドランク |
| dカード GOLD U | ゴールドUランク |
| dカード レギュラー | 通常ランク |
| ● ご利用なし | dカード未利用（デフォルト選択状態） |

- ラジオボタンの選択肢は **汎用マスタの内容をもとに動的に生成** される
- 契約中のdカードランクに応じて表示項目が変わる
- 画面キャプチャでは「ご利用なし」が選択状態（●）となっている

## 3. データ取得に関する課題と対応案

### データソース

契約中サービス情報の取得パス:

```
顧客情報.基本契約情報.契約中サービスカテゴリリスト.サービス区分 = '03'（オプション）
顧客情報.基本契約情報.契約中サービスカテゴリリスト.契約中サービス情報リスト.サービスコード
```

### 課題

**料SIMのオプションマスタにはdカードに関するサービスコードは登録されていない**

### 対応案

| 案 | 内容 | 備考 |
|----|------|------|
| 対応案1 | 汎用マスタにサービスコード（value1）/ サービス名称（value2）を登録する | シンプルな対応 |
| 対応案2 | オプションマスタをメンテナンスして、汎用マスタにはサービスコードのみ登録。名称はオプションマスタから取得する | マスタ分離パターン |

## 4. home 5G 顧客詳細画面

### 画面全体構成

顧客詳細画面は大きく以下のセクションで構成される。

#### 左側パネル（基本情報・予約・操作）

| セクション | 内容 |
|-----------|------|
| 基本情報 | 電話番号、利用データ量、料金プラン設定データ量 |
| ご予約情報 | 予約状態（「ご予約はありません」等）、審査結果確認・発注予約確認・来店予約確認リンク |
| スマホ契約 | 月額・料金・利益の各種指標 |
| 操作リンク | 料金・口座情報をみる、利益状態をみる、データ通信量確認をみる、精算一覧をみる |
| スマホ変更予約 | 予約状態（「ご予約はありません」等）、スマホ変更予約確認・商品予約確認リンク |

#### 右側パネル（ご契約中のサービス）

各サービスカテゴリの詳細（後述）。

## 6. システム間連携（ALADIN・LAMP）

### ALADIN

- 顧客契約情報の管理システム
- home 5Gプラン契約時の制約確認に使用
- 顧客番号・電話番号（070-1636-3685）による検索が可能
- 画面上部に「※home 5Gプラン契約時は光の契約は不可」の注記が表示される
- **契約中サービス一覧**: グリッド形式で契約中サービスの一覧を表示
- **特約サービス**: 特約サービスの情報セクションが別途表示される

### LAMP

- 端末情報・契約情報の参照システム
- home 5G端末（HR02等）の端末画像と情報を表示
- 契約プラン確認に使用
- 「ご契約端末をリフレスタルトしてください、home 5Gプランのみ」等の注意メッセージが表示される
- 「home 5G端末が契約可能なプランは『home 5Gプラン』のみ」という制約が画面上に明示される

### Excelシートタブ構成

元資料のExcelには以下のタブが存在する:

| タブ名 | 内容 |
|--------|------|
| 利用中端末（home 5G以外） | home 5G以外の端末情報 |
| **dカード** | dカード設定処理フロー（メイン） |
| 利用中端末（home 5G） | home 5G端末の顧客詳細画面 |
| 光 | 光回線関連情報 |

## 7. 制約事項・注意点

### home 5Gプラン契約時の制約

- **home 5Gプラン契約時は光（ドコモ光）の契約は不可**（ALADIN画面上にも注記あり）
- home 5G端末が契約可能なプランは「home 5Gプラン」のみ（LAMP画面上にも注意表示あり）

### dカード関連の制約

- 料SIMのオプションマスタにdカードのサービスコードが未登録のため、汎用マスタまたはオプションマスタのメンテナンスが必要
- dカード選択ラジオボタンは汎用マスタから動的に生成するため、マスタデータの整備が前提となる
- デフォルトでは「ご利用なし」が選択状態

### データ参照パス

```
サービス区分 = '03'（オプション）でフィルタリング
↓
契約中サービスカテゴリリスト → 契約中サービス情報リスト → サービスコード
```
