## 1. 概要

### 1.1 本設計書の目的

チケット詳細モーダル（`TodoDetailModal.vue`）に編集機能を追加するためのフロントエンド基本設計を定義する。

### 1.2 フロントエンドの役割

| 責務 | 説明 |
|------|------|
| 画面表示 | チケット情報の表示モード・編集モードの切り替え表示 |
| ユーザー操作 | 編集フォームの入力・保存・キャンセル操作の受付 |
| API連携 | バックエンドAPI（PUT /api/todos/{id}）との通信 |
| 状態管理 | 編集中データの一時保持、保存後の画面反映 |

## 2. 技術要件

### 2.1 使用技術

| 項目 | 技術 |
|------|------|
| フレームワーク | Vue.js 3 (Composition API) |
| 言語 | TypeScript |
| 状態管理 | Pinia |
| ルーティング | Vue Router 4 |
| ビルドツール | Vite |
| API通信 | Fetch API |
| スタイル | CSS3 (Scoped Styles) |

### 2.2 コンポーネント構成（Vue.js）

| 項目 | 方針 |
|------|------|
| コンポーネント分割 | 編集フォームを`TodoEditForm.vue`として分離 |
| 命名規則 | PascalCase（TodoEditForm.vue） |
| スタイル | Scoped CSS を使用 |
| 型定義 | すべてのコンポーネントにTypeScript型定義 |
| Props/Emits | 型安全な defineProps / defineEmits を使用 |

### 2.3 状態管理方針（Pinia）

| 項目 | 方針 |
|------|------|
| ストア設計 | 既存の`useTodoStore`に`updateTodo`アクションを追加 |
| API呼び出し | ストアのActionsで実施 |
| ローカル状態 | 編集中データはコンポーネントのrefで管理 |
| 更新後の反映 | ストアの`fetchTodos`で一覧を再取得 |

## 6. データフロー

### 6.1 編集から保存までのフロー

```
1. ユーザーが「編集」ボタンをクリック
   │
   ▼
2. TodoDetailModal: isEditMode = true に変更
   │  └─ 表示モード → 編集モード（TodoEditForm表示）
   │
   ▼
3. ユーザーがフォームで値を編集
   │  └─ TodoEditForm内のローカル状態で管理
   │
   ▼
4. ユーザーが「保存」ボタンをクリック
   │
   ▼
5. TodoEditForm: saveイベントを emit（UpdateTodoRequest）
   │
   ▼
6. TodoDetailModal: updateTodo アクションを呼び出し
   │  └─ todoStore.updateTodo(todoId, request)
   │
   ▼
7. todoStore: API呼び出し（PUT /api/todos/{id}）
   │  └─ 成功後、fetchTodos で一覧を再取得
   │
   ▼
8. TodoDetailModal: todoUpdated イベントを emit
   │  └─ isEditMode = false に変更（編集モード終了）
   │
   ▼
9. 親コンポーネント: 一覧を更新済み（storeが更新されているため）
```

### 6.2 キャンセル時のフロー

```
1. ユーザーが「キャンセル」ボタンをクリック
   │
   ▼
2. TodoEditForm: cancelイベントを emit
   │
   ▼
3. TodoDetailModal: isEditMode = false に変更
   │  └─ 編集モード → 表示モード（変更は破棄）
```

## 7. 非機能要件

### 7.1 ユーザビリティ

| 項目 | 要件 |
|------|------|
| 応答性 | 編集モード切替は即座に反応 |
| フィードバック | 保存処理中はボタン無効化とローディング表示 |
| 確認 | 保存成功時は編集モードを終了して表示モードに戻る |

### 7.2 アクセシビリティ

| 項目 | 対応 |
|------|------|
| キーボード操作 | Escキーでモーダルを閉じる（既存機能維持） |
| フォーカス管理 | 編集モード開始時、タイトル入力欄にフォーカス |
