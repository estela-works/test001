# Phase 3｜差分チェック

## 問い

> 前版・類似設計・最新仕様との差分で、意図しない脱落がないか？

## チェック対象

- 改版で消えたテーブル・カラム定義が実は必要だった
- 仕様更新がDB設計書に未反映
- 類似DB設計との比較で要素が欠落

## 実行手順

### Step 1｜前版との差分確認

設計書に前版が存在する場合、差分を取り、削除・変更された箇所を列挙する。

```
| # | 変更種別 | 該当箇所 | 前版の記述 | 現版の記述 | 削除意図 |
|---|---------|---------|-----------|-----------|---------|
| 1 | 削除    | ...     | ...       | （なし）   | 意図的/要確認 |
| 2 | 変更    | ...     | ...       | ...       | -       |
```

「削除意図」が不明な項目は、設計者に確認を求める。

### Step 2｜類似設計との構造比較

同種のDB詳細設計書と、構造レベルで比較する。

```
| # | 構成要素 | 既存設計にあるか | 今回の設計にあるか | 差異の理由 |
|---|---------|----------------|-------------------|-----------|
| 1 | ...     | あり           | あり              | -         |
| 2 | ...     | あり           | なし              | 要確認     |
| 3 | ...     | なし           | あり              | 新規追加   |
```

### Step 3｜参照仕様書の最新版確認

設計書が参照している仕様書（specs/配下）が最新版かを確認する。

```
| # | 参照仕様書 | 設計書での参照日/版 | 最新版 | 差異 |
|---|-----------|-------------------|--------|------|
| 1 | ...       | ...               | ...    | あり/なし |
```

## 判定基準

- 全Stepで意図しない脱落・未反映がなければPass
- 要確認項目がある場合は、設計者に確認後に修正
