# 案件スコープドキュメント

案件ごとの設計ドキュメントを格納するフォルダ。

## フォルダ命名規則

```
YYYYMMDD_連番_案件名
```

- **YYYYMMDD**: 案件開始日（西暦4桁 + 月2桁 + 日2桁）
- **連番**: 同日に複数案件がある場合の識別番号（01, 02, 03...）
- **案件名**: 案件の内容を表す簡潔な名前

例: `20250108_01_ユーザー管理機能`, `20250108_02_バグ修正`

## フォルダ構成

```
projects/
├── YYYYMMDD_連番_案件名/    # 案件ごとのフォルダ
│   ├── requirements.md      # 要件整理書
│   ├── basic-design-*.md    # 基本設計書
│   ├── detail-design-*.md   # 詳細設計書
│   └── test-spec*.md        # テスト仕様書
└── template/                # テンプレート
```
