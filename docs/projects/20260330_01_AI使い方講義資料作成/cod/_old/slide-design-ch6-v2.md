# スライド設計: 第6章 なぜSPEC&Projectが今の開発に有効なのか

## 章の役割

- 第5章の提案を、課題対照で検証して妥当性を確定する
- 第1章の原理（コンテキスト品質）と実運用の効果を接続する
- 聴講者が「自分の現場に当てはめられる」状態でクロージングへ渡す

## 感情設計

検証モード → 納得 → 確信 → 行動準備

## 圧縮方針（v1→v2）

- 旧12枚→7枚。課題別アンサーをクラスタ化して密度を上げる
- 6-2〜6-4を「情報品質課題」、6-5〜6-7を「継承・運用課題」に統合
- テンプレート論点は独立1枚で残し、実装時の再現性を担保
- 章末で「共通解=コンテキスト密度向上」に回収して締める
