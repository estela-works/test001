# スライド設計: クロージング

## 章の役割

- 第0〜6章の論理を1本線で再確認し、理解を固定する
- 核心メッセージを短く強く言語化して持ち帰り可能にする
- 実行開始のハードルを下げ、講義後の最初の行動に接続する

## 感情設計

整理 → 確信 → 行動意欲

## 圧縮方針（v1→v2）

- 旧4枚維持。役割が明確なため削減しない
- まとめ/核心/初手/締めを1枚ずつ固定し、終わり方をブレさせない
- 主張は繰り返しすぎず、行動導線を優先する

---

## スライド一覧

### C-01: 論理の流れを1枚で再確認

| 項目 | 内容 |
|------|------|
| 種別 | まとめ |
| キーメッセージ | 原理→問題→歴史→転換→手法→検証が一直線でつながる |
| 内容 | 第0〜6章の要点を1行ずつ配置した全体フロー図を提示 |
| 話者ノート | 「話が飛んでいない」ことを確認し、納得感を閉じる |
| 感情 | 整理・理解の固定 |

---

### C-02: 核心メッセージ

| 項目 | 内容 |
|------|------|
| 種別 | コンテンツ |
| キーメッセージ | AIの能力を引き出すために情報を整備するのではない。情報整備そのものをAIが支援する |
| 内容 | 3行構成で核心を表示（情報分割、品質向上、好循環） |
| 話者ノート | この講義で最も持ち帰ってほしい1文として強調する |
| 感情 | 確信 |

---

### C-03: 最初の一歩（行動提案）

| 項目 | 内容 |
|------|------|
| 種別 | コンテンツ |
| キーメッセージ | 完璧な導入計画より、1つのSPECと1つのProjectを回し始めることが重要 |
| 内容 | 初手チェックリスト（対象範囲選定、SPEC初版、Project起票、完了時更新）を提示 |
| 話者ノート | スモールスタートを具体化し、明日実行できる粒度に落とす |
| 感情 | 行動意欲 |

---

### C-04: 締め＋Q&A導入

| 項目 | 内容 |
|------|------|
| 種別 | ブリッジ |
| キーメッセージ | 好循環に入るのは「準備が整ってから」ではなく「回し始めたとき」 |
| 内容 | 締めの一言、質疑への導線、議論したい論点（運用/テンプレ/評価）を提示 |
| 話者ノート | 反論や懸念を歓迎し、実装議論に転換する姿勢を示す |
| 感情 | 前向きな対話姿勢 |
