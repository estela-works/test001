# スライド設計: 第2章 LLMによる開発の課題

## 章の役割

- 第1章で確立した3条件（正確・一貫・最新）で現場実態を評価する
- AI活用不全の原因を「モデル性能」から「情報基盤設計」へ再定義する
- SSOTと役割分離（保管/伝達）を次章以降の解法軸として導入する

## 感情設計

共感 → 問題の再定義 → 構造理解 → 解法への期待

## 圧縮方針（v1→v2）

- 旧9枚→6枚。症状説明を集約し、原因と構造に時間を配分
- 「現場あるある」列挙を1枚に圧縮し、SSOT欠如へ一直線で接続
- SSOT定義・成立困難の理由・分離方針を3枚で明確化
- 第3章への橋渡しは「なぜ放置されたか」の問いに絞る
