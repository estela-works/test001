# スライド設計: 第4章 AIが変える情報管理のコスト構造

## 章の役割

- 第3章で示した歴史的トレードオフの前提が変わったことを示す
- 「情報管理は重すぎる」という旧常識を、現在のコスト構造で再評価する
- 好循環/停滞の分岐を示し、第5章の手法提示に必然性を持たせる

## 感情設計

希望 → 高揚 → 危機感 → 実装したい気持ち

## 圧縮方針（v1→v2）

- 旧8枚→5枚。コスト構造変化と循環構造に集中
- 「コスト低下」と「品質関門は人間」のセットを1枚で提示
- 好循環/悪循環は対比1枚で分岐条件を明示
- 第3章課題への実現可能性を整理し、手法導入へ接続
