# スライド設計: 第1章 LLMの基礎

## 章の役割

- 講義後半の前提となるLLMの動作原理を短時間で共有する
- 「コンテキストの質＝出力の質」を講義全体の共通原理として固定する
- 原理から運用ルールを導出できる状態を作り、第2章の問題提起へ接続する

## 感情設計

共感 → 理解 → 腹落ち → 実践意欲

## 圧縮方針（v1→v2）

- 旧10枚→6枚。原理説明の重複を統合し、実務に効く論点へ集中
- 「トークン予測」「ハルシネーション」「コンテキスト条件」を1本の因果で接続
- 活用ノウハウは2枚（セッション分離/探索分離）を1枚に統合
- 詳細例（長い補足）は口頭で補完し、スライドは判断軸を残す
