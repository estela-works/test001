# スライド設計: 第6章 なぜSPEC&Projectが今の開発に有効なのか

## 講義全体の目的

エージェントAIを活用したシステム開発への転換を提案する講義。
「AIネイティブ開発」とは何かをフレーム化し、現場のシステム開発手法が抱える歴史的課題を解きほぐした上で、具体的な手法（SPEC&Project）を提案し、その有効性を論証する。全6章＋クロージングの59枚構成。

## 章の目的

- 第2〜3章で提起した全課題に対し、SPEC&Projectによる具体的アンサーを一覧で示す
- 2層分離（SSOT層＋アウトプット層）の設計思想を独立スライドで印象付ける
- 第0章のフレームを完全回収し、「AIネイティブ開発」の定義を完成させる

## 感情設計

確信の積み上げ → 2層分離のエレガンスへの感動 → 第0章回収のカタルシス

## 圧縮方針（v1→v2）

- 旧12枚→5枚。課題別アンサーの個別展開（旧6-03〜6-07）を一覧表1枚に統合
- 2層分離（旧6-08）は独立スライドとして維持 — 講義の知的クライマックス（案H適用）
- テンプレート（旧6-09）は2層分離スライドの補足に吸収
- 第0章フレーム回収（旧6-10）＋まとめ（旧6-11）＋ブリッジ（旧6-12）を1枚に統合
- 一覧表はアニメーション段階表示で伏線回収のリズムを部分再現
- 課題別アンサーの詳細（具体的パス指定例、11案件実証エピソード等）は配布資料（75枚版）に委譲
