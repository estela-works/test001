# スライド設計: 第4章 AIが変える情報管理のコスト構造

## 講義全体の目的

エージェントAIを活用したシステム開発への転換を提案する講義。
「AIネイティブ開発」とは何かをフレーム化し、現場のシステム開発手法が抱える歴史的課題を解きほぐした上で、具体的な手法（SPEC&Project）を提案し、その有効性を論証する。全6章＋クロージングの59枚構成。

## 章の目的

- AIの登場によりパラダイムが変わったことを示す（第0章のフレーム適用）
- 好循環のフライホイール構造を提示し、「早く始めた者が有利」という動機付けをする
- 第3章の全課題がAIで解決に向かうことを示し、第5章への期待を最大化する

## 感情設計

希望 → 高揚感 → 危機感（悪循環側にいる焦り）→ 「今すぐ始めたい」

## 圧縮方針（v1→v2）

- 旧10枚→8枚。章タイトル、ブリッジを含む全8枚構成を維持
- 好循環（4-04）と悪循環（4-05）は対比の視覚インパクトが講義の動機付けに直結するため分離を維持
- 第3章課題の解決一覧（4-06）は第3章との接続点として独立維持
- まとめ（4-07）で第0章フレームを再適用し、構造的な腹落ちを作る

### 4-02: 情報の記載・更新コストの劇的な低下

**コンセプト:**
第4章の核心的主張を最初に提示するスライド。「情報管理コストが高い→管理しないのが合理的」という第3章の結論を、「コストが桁違いに下がった→管理する方が合理的」に反転させる。対比レイアウトで「以前」と「現在」の構造的変化を視覚化し、人間の役割が「書く人→確認する人」に変わることを示す。

**文脈情報:**
- 講義の目的: AIネイティブ開発への転換を提案する（全59枚）
- 章の目的: AIによるコスト構造の激変を示し、好循環フライホイールで動機付けする

- 次スライド: 4-03 暗黙知を形式知に転換できる時代。コスト低下の具体的な応用に進む
- このスライドの役割: 第3章の「合理的トレードオフ」を根底から覆す証拠の提示。ここで「バランスの逆転」を納得させなければ、以降の章が成立しない

| 項目 | 内容 |
|------|------|
| 種別 | 対比 |
| キーメッセージ | 人間の役割が「書く人」→「確認する人」に。0→1の執筆コストと確認・修正コストは桁が違う |
| 左カラム（以前） | 情報管理コスト >> 開発コスト → 諦めるのが合理的 |
| 右カラム（現在） | 情報管理コストが劇的低下 → 管理する方が合理的な領域が拡大 |
| 補足 | ただしコストは0ではない。AIの出力を人間が確認するコストは残る。重要なのはバランスの逆転 |
| 話者ノート | 「第3章で見たように、情報管理を諦めたのは合理的でした。しかしその前提が崩れつつある。AIが0→1の執筆を担い、人間は確認・修正に集中できる。この差は桁違いです」 |

### 4-03: 暗黙知を形式知に転換できる時代

**コンセプト:**
第3章で示された「暗黙知の限界」に対する直接的な回答。暗黙知を否定するのではなく、暗黙知＋形式知＝チーム能力の拡張という「増幅」フレームを提示する。ベテランの経験が消えるのではなく到達範囲が広がるというメッセージが、防衛反応を和らげつつ希望を生む。第3章3-04/3-05で張った「暗黙知の否定ではない」という伏線の回収。

**文脈情報:**
- 講義の目的: AIネイティブ開発への転換を提案する（全59枚）
- 章の目的: AIによるコスト構造の激変を示し、好循環フライホイールで動機付けする

- このスライドの役割: 暗黙知と形式知のトレードオフ解消を宣言。ベテランの経験価値を肯定しながら、形式知化への動機を作る。第3章3-05「暗黙知の限界」への直接的な回答

| 項目 | 内容 |
|------|------|
| 種別 | コンテンツ |

### 4-04: 好循環のフライホイール

**コンセプト:**

### 4-05: 悪循環 — 停滞のループ

**コンセプト:**
4-04の好循環と同じ構造を逆回転で見せ、「自分のチームはどちら側にいるか？」という自己診断を促す。好循環と悪循環を左右に並べることで、構造の対称性が際立ち、「入口の選択が全てを決める」というメッセージが視覚的に伝わる。危機感と希望が同時に発生するスライド。

**文脈情報:**
- 講義の目的: AIネイティブ開発への転換を提案する（全59枚）
- 章の目的: AIによるコスト構造の激変を示し、好循環フライホイールで動機付けする
- 前スライド: 4-04 好循環フライホイール。「回せば加速する」美しい構造を見た直後
- 次スライド: 4-06 第3章の課題がすべて解決に向かう。悪循環からの脱出手段があることを示す
- このスライドの役割: 好循環と悪循環の対比で危機感を生む。「今の位置は問わない、どちらに入るかの選択が重要」という前向きメッセージで行動への意欲を引き出す

| 項目 | 内容 |
|------|------|
| 種別 | 図解 |
| キーメッセージ | 逆回転: 暗黙知放置→コンテキストなし→AI低品質→「AI使えない」判断→AI活用が進まない→停滞 |
| 内容 | 4-04と対になる悪循環図。同じ構造だが逆方向 |
| ビジュアル | 好循環と悪循環を左右に並べて対比 |
| 話者ノート | 「好循環の裏には必ず悪循環があります。情報を整備しない→AIに渡せるコンテキストがない→AI出力が低品質→『やっぱりAI使えない』と判断→ますます情報整備しない。心当たりのある方もいるかもしれません」。間を取ってから「**今の位置は問いません。どちらの循環に入るかの選択が重要です**」 |
| 感情 | 「うちのチーム、まさに停滞側だ…」→ 危機感。「好循環に入れば加速する＝早く始めた者が圧倒的有利」 |
| 配慮（ベテラン） | 悪循環の図を見て「自分がチームを悪循環に導いた可能性」に気づくギクリ感がある。しかし第2〜3章で「構造の問題」フレームが既に提示されているため、個人攻撃としては受け取りにくくなっている。口頭で「**今の位置は問わない。どちらの循環に入るかの選択が重要**」と前向きに |
