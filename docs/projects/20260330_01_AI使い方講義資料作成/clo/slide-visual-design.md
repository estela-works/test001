# スライド ビジュアルデザイン仕様書

## 基本コンセプト

**明るく知的で、信頼感のあるテック講義スライド**

- 白ベースの明るいトーン
- 余白を活かしたクリーンなレイアウト
- ブランドグリーンを軸にした最小限の配色
- 講義資料としての可読性・視認性を最優先

---

## カラーシステム

### ブランドカラーの導出

会社ロゴカラー `#28AA3C`（HSL: 129°, 62%, 41%）を起点に、色彩理論に基づく最小パレットを構成する。

```
色相環（関係性）:

        0° (Red)
         |
   309°──┼──129° ◀ ブランドグリーン #28AA3C
  (補色) |
       180° (Cyan)

  補色（180°対向）: 309° → マゼンタパープル
```

### パレット定義

#### 1. プライマリ（ブランドグリーン系）

ロゴカラーから明度・彩度を調整した5段階。スライドの主要アクセントに使用。

| レベル | HEX | 用途 |
|--------|-----|------|
| Primary-900（最濃） | `#145C20` | 強い強調が必要なとき（見出しの下線等） |
| **Primary-600（基準）** | **`#28AA3C`** | **ロゴカラー。メインアクセント** |
| Primary-400（明） | `#5CC46C` | アイコン、ブレットマーク |
| Primary-100（淡） | `#D4EDDA` | カード背景、強調エリアの背景 |
| Primary-50（極淡） | `#F0F8F2` | セクション区切りの背景 |

#### 2. コンプリメンタリ（補色系）

補色関係（309°）から導出。否定・警告・対比の「旧い側」に限定して使用。

| レベル | HEX | 用途 |
|--------|-----|------|
| Comp-600（基準） | `#AA2896` | 否定マーク（✗）、警告アクセント |
| Comp-100（淡） | `#F5E0F2` | 対比の「旧い側」背景 |

#### 3. ニュートラル（グリーンティント・グレー系）

ブランドグリーンの色相（129°）を微量含んだグレースケール。無彩色より統一感が出る。

| レベル | HEX | 用途 |
|--------|-----|------|
| Neutral-900 | `#1E352A` | 本文テキスト（主）|
| Neutral-600 | `#6B7E74` | 補足テキスト、注釈 |
| Neutral-300 | `#B0BFB6` | ボーダー、区切り線 |
| Neutral-100 | `#EDF5F0` | カードの背景（プライマリほど強調しないとき） |
| Neutral-0 | `#FFFFFF` | スライド背景 |

### 使用ルール

- **使う色は上記3系統のみ**。章ごとに色を変えない
- プライマリ系 : ポジティブな要素、強調、アクセント
- コンプリメンタリ系 : ネガティブな要素、対比の「旧」側に限定
- ニュートラル系 : テキスト、背景、構造線
- 1枚のスライド内でプライマリとコンプリメンタリを同時に使ってよいのは**対比構造のとき**のみ

## 要素デザイン

### 背景

- メイン: `Neutral-0`（白）
- エリア区切り: `Primary-50` または `Neutral-100` の矩形

### テキスト

- 本文: `Neutral-900` on 白背景
- 強調語句: `Primary-600` または **Bold** で区別（色変更とBoldの併用は避ける）
- 否定的な語句: `Comp-600`

### ボックス / カード

- 通常: `Neutral-100` 背景 + `Neutral-300` ボーダー（1px）、角丸 8px
- 強調: `Primary-100` 背景 + `Primary-600` 左ボーダー（4px）
- 否定: `Comp-100` 背景 + `Comp-600` 左ボーダー（4px）

### 線・区切り

- 区切り線: `Neutral-300`（1px）
- 強調セパレータ: `Primary-600`（2–4px）
- フロー矢印: `Primary-600`

### 記号・マーク

| 記号 | 意味 | 色 |
|------|------|-----|
| ✓ / ○ | 肯定・正しい | Primary-600 |
| ✗ / × | 否定・問題 | Comp-600 |
| ● | ブレット | Primary-400 |
| ▶ | 方向・遷移 | Primary-600 |

### 対比構造（旧/新）

- 「旧」側: `Comp-100` 背景 + `Comp-600` 左ボーダー
- 「新」側: `Primary-100` 背景 + `Primary-600` 左ボーダー
- ラベル「旧」: `Comp-600`、ラベル「新」: `Primary-600`

## レイアウト原則

- **余白優先**: コンテンツを詰め込まない。情報は上部60%に集中させ、下部に余白を残す
- **左右マージン**: 8%以上
- **フッター**: 必要に応じて章タイトル（小、`Neutral-600`）＋スライド番号を右下に配置
- **1スライド1メッセージ**: 視覚要素もメッセージに集中させる
