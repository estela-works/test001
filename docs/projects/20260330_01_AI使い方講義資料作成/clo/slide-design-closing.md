# スライド設計: クロージング

## 講義全体の目的

エージェントAIを活用したシステム開発への転換を提案する講義。
「AIネイティブ開発」とは何かをフレーム化し、現場のシステム開発手法が抱える歴史的課題を解きほぐした上で、具体的な手法（SPEC&Project）を提案し、その有効性を論証する。全6章＋クロージングの59枚構成。

## 章の目的

- 全章の論理を一気通貫で振り返り、記憶を定着させる
- 核心メッセージを1文に凝縮して印象付ける
- 「まず小さく始める」具体的な第一歩を示し、行動につなげる
- 第0章の問いを回収し、講義全体を円環構造で閉じる

## 感情設計

振り返りの充足 → 核心の理解 → 「自分が始める」使命感 → 最大の伏線回収

### C-02: Core Message（核心メッセージ）

**コンセプト:**
講義全体で最も伝えたい「逆転の構造」を1文に凝縮するスライド。通常のslide-head（タイトル＋メッセージ）を使わず、画面全体を核心メッセージに使う特殊レイアウト。多くの聴衆は「AIの能力を引き出すために情報を整備しなければならない」と受け取りがちだが、実は「情報を整備する行為自体をAIが支援する」という好循環こそが核心である。この逆転に気づく瞬間が、講義の最深部のインパクトになる。最小限のテキストで最大のインパクトを狙う。

**文脈情報:**
- 講義の目的: AIネイティブ開発への転換を提案する（全59枚）
- 章の目的: 全章の論理を振り返り、核心メッセージで締め、行動につなげる
- 前スライド: C-01 振り返り。全6章の論理線を再確認した直後。聴衆は「全部つながった」と感じている
- 次スライド: C-03 最初の一歩。核心を理解した上で「では何から始めるか」という行動に移る
- このスライドの役割: 講義全体の核心を1文に凝縮し、「逆転の構造」を最も印象的な形で刻み込む

| 項目 | 内容 |
|------|------|
| 種別 | コンテンツ（特殊レイアウト: slide-headなし、core-message全画面） |
| タイトル | （なし。フッターに「Core Message / Closing」と表示） |
| メインメッセージ | （なし。スライド全体が核心メッセージそのもの） |
| 内容 | 否定文「AIの能力を引き出すために情報を整備するのではない。」（core-deny）、セパレータ線、肯定文「情報を整備する行為自体をAIが支援する。」（core-assert）を中央に大きく表示。下部に補足「適切に分割された正確な情報が、AIの性能を引き上げる。だからまず始めることが大事。好循環は最初の一歩から回り始める。」（core-supplement） |
| 話者ノート | 「ここが今日の講義の一番深いところです。情報整備はAI活用の"前提条件"ではありません。AI自身が情報整備を手伝ってくれる。整備すればAIが良くなり、AIが良くなればさらに整備が楽になる。第4章で見た好循環そのものです。だからまず始めることが大事なんです」 |
| 感情 | 逆転の核心が刺さる瞬間。「前提条件だと思っていたものが、実は結果だった」 |
| 配慮（ベテラン） | ベテランは「情報整備は重荷」という長年の実感がある。口頭で「**情報整備が辛かったのは、コストが高すぎたから。AIがそのコストを下げてくれる今なら、皆さんが"本当はやりたかったこと"が現実的になります**」と、ベテランの過去の判断を肯定しつつ、新しい可能性として提示する |

**内容設計（ASCII図）:**
```
+================================================================+
|                                                                  |
|                                                                  |
|      AIの能力を引き出すために                                    |
|      情報を整備するのではない。              （core-deny）       |
|                                                                  |
|      ━━━━━━━━━━━━━━━━━━━━━              （core-separator）     |
|                                                                  |
|      情報を整備する行為自体を                                    |
|      AIが支援する。                          （core-assert）     |
|                                                                  |
|      ┌──────────────────────────────────────────┐                |
|      │ 適切に分割された正確な情報が、AIの性能を  │                |
|      │ 引き上げる。だからまず始めることが大事。  │                |
|      │ 好循環は最初の一歩から回り始める。        │（core-supplement）|
|      └──────────────────────────────────────────┘                |

- フッター: 「Core Message / Closing」

### C-03: １案件から運用転換を始める

**コンセプト:**
理解を行動に変換するスライド。講義の内容がどれほど論理的でも、「で、何から始めればいいの？」に答えなければ行動につながらない。大規模変革ではなく「1つのSPECを作り、1つのProjectで更新してみる」という最小単位の行動を提示し、心理的ハードルを極限まで下げる。フローピル「小さく始める → 1回回す → 結果で広げる」で行動ステップを視覚化し、好循環の起点は「まず始めること」であることを強調する。

**文脈情報:**
- 講義の目的: AIネイティブ開発への転換を提案する（全59枚）
- 章の目的: 全章の論理を振り返り、核心メッセージで締め、行動につなげる
- 前スライド: C-02 核心メッセージ。「情報整備をAIが支援する」という逆転の構造を理解した直後
- 次スライド: C-04 第0章の回収。行動への意志が固まった状態で、講義全体の伏線回収に入る
- このスライドの役割: 理解を行動に変換する。「大改革」ではなく「小さな一歩」で始められることを示し、着手の心理的ハードルを下げる

| 項目 | 内容 |
|------|------|
| 種別 | コンテンツ |
| タイトル | １案件から運用転換を始める（13字） |
| メインメッセージ | 運用転換は小さく始める方が抵抗も小さく成果も早く見える（27字） |
| 内容 | 2枚のアクションカード: (1)「1つの SPEC」── 今の正しい姿を、まず一箇所に固定する／補足「まずは API 仕様や業務ルールなど、1つの領域だけでもよい。」 (2)「1つの Project」── その SPEC を実際に更新する案件を一度回してみる／補足「全社展開ではなく、1チーム・1案件で結果を見るところから始める。」。フローピル「小さく始める → 1回回す → 結果で広げる」。締めのcallout「好循環が一度回り始めると、もう情報が散在した状態には戻りにくくなる」 |
| 話者ノート | 「大きな組織変革は必要ありません。まず1つのシステムのSPECを作ってみてください。次の案件でProjectを立て、SPECを起点に設計してみてください。AIに渡すコンテキストの質が変わります。結果が出れば、次は自然に広がります」 |
| 感情 | 「自分にもできる」という安心感 → 「自分がチームを変える」使命感 |
| 配慮（ベテラン） | 「やれ」ではなく「あなたが判断する」スタンス。口頭で「**やるかどうかは皆さんが判断すること。まず1つのSPECを作り、1つのProjectで更新してみる。結果を見てから次を決める。それがこれまで皆さんが変化を推進してきたときのやり方と同じはず**」と、ベテランの行動パターン（実証→判断→展開）に寄り添い、主体性を尊重する |

**内容設計（ASCII図）:**
```

|  １案件から運用転換を始める                                      |

### C-04: 「AIネイティブ開発」とは何か

**コンセプト:**
講義全体の最終スライドであり、最大の伏線回収。第0章で投げかけた「AIネイティブ開発って何だと思いますか？」という問いを lead-card で再表示し、全スライドを経て辿り着いた答えを big-conclusion callout で提示する。冒頭と末尾が対になる円環構造により、聴衆は「最初の問いに答えが出た」という知的充足を得る。さらにフローピルで講義全体の論理線（コンテキストの質 → 言語化コストの逆転 → 正しい知識を残す仕組み）を章番号付きで可視化し、答えが論理的帰結であることを示す。

**文脈情報:**
- 講義の目的: AIネイティブ開発への転換を提案する（全59枚）
- 章の目的: 全章の論理を振り返り、核心メッセージで締め、行動につなげる
- 前スライド: C-03 最初の一歩。「1つのSPECから始める」という具体的行動が示された直後。聴衆は行動への意志を持った状態
- 次スライド: なし（講義の終了）
- このスライドの役割: 第0章の問いの完全回収。全スライドの論理を1つの定義に収束させ、知的充足と行動への決意を同時に生む。講義の最終印象を決める

|------|------|
| 種別 | コンテンツ |

| メインメッセージ | AIを使う量ではなく、AIに渡す情報の質を高め続ける構造を持つことが本質である（38字） |

| 感情 | 最大の伏線回収。「最初の問いに答えが出た」。知的充足と行動への決意が同時に生まれる |
| 配慮（ベテラン） | 最終スライドでベテランに残すべき印象は「自分の経験の延長線上にある変化」。口頭で「**インターネットネイティブもクラウドネイティブも、皆さんが推進してきた。AIネイティブも同じです。前提が変わったから、最適解を更新する。それだけのことです。皆さんなら、できます**」と、過去の実績への敬意と未来への信頼を同時に伝えて締める |
