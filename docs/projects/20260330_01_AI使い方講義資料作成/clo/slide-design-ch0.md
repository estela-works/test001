# スライド設計: 第0章 AIネイティブ開発とは何か（アイスブレイク）

## 講義全体の目的

エージェントAIを活用したシステム開発への転換を提案する講義。
「AIネイティブ開発」とは何かをフレーム化し、現場のシステム開発手法が抱える歴史的課題を解きほぐした上で、具体的な手法（SPEC&Project）を提案し、その有効性を論証する。全6章＋クロージングの59枚構成。

## 章の目的

- 講義全体のフレーム（制約→最適化対象→合理的戦略）を提示する
- 「○○ネイティブ＝新技術を使うことではない」という視点を獲得させる
- 「AIネイティブ開発で脱構築されるべき常識とは？」という問いを残し、全章への期待を作る

## 感情設計

興味 → 「知ってるつもり」への揺さぶり → パターン認識の快感 → 期待

## 圧縮方針（v1→v2）

- 旧12枚→7枚。○○ネイティブ3例の個別展開は全て維持（ペルソナの自分ごと感＋パターン発見体験を守る）
- 問いかけ＋ゆさぶり（旧0-02, 0-03）を1枚に統合
- 比較表（旧0-07）をカット — 3例が個別展開済みのため、5ステップ構造で抽象化すれば十分。比較表形式は第6章で初登場させ、AIネイティブ行を含む完成版として提示する
- 5ステップ因果構造＋本質（旧0-08, 0-09）を1枚に統合
- 伏線＋講義の地図＋ブリッジ（旧0-10〜0-12）を1枚に統合

### 0-06: 共通構造＋○○ネイティブの本質

**コンセプト:**
第0章の知的クライマックス。3つの事例で「何となく見えたパターン」を5ステップのフロー図で明示的に構造化し、さらに本質を1文に凝縮する。「ネイティブ＝ツールを使うことではない」という発見が、この講義全体のフレームになる。第6章で再び登場する伏線でもある。

**文脈情報:**
- 講義の目的: AIネイティブ開発への転換を提案する（全59枚）
- 章の目的: 「○○ネイティブ」の共通構造を発見させ、講義全体への期待を作る
- 前スライド: 0-05 クラウドネイティブ。3例目が終わり「全部同じ構造だ」と確信した直後
- 次スライド: 0-07 講義の地図＋ブリッジ。「ではAIネイティブでは何が脱構築されるのか？」と問いを残して全章ロードマップへ
- このスライドの役割: 3事例の抽象化＋本質の提示。講義全体で繰り返し参照されるフレーム（5ステップ構造）の定義スライド

| 項目 | 内容 |
|------|------|
| 種別 | 図解 |
| キーメッセージ | ○○ネイティブとは、新技術を使うことではない。旧い最適化対象を捨て、新しいボトルネックに対して最適化する世界観で行動すること |
