○○ネイティブの共通構造と本質
ネイティブとは新技術導入でなく前提変化による最適化先の更新である
Internet Native
配信から発見へ
配信制約が消えると、競争は届ける力から見つかる力へ移る。
Cloud Native
大変更・低頻度から小変更・高頻度へ
変更コストが下がると、大きく固めるより小さく速く変える方が強くなる。
STEP 1
技術革新で制約が変わる
高かったコストが一気に下がり前提が崩れる
→
STEP 2
コスト構造が激変する
希少だったものが余剰になり新しいボトルネックが立つ
→
STEP 3
最適化対象が移動する
新しい制約に合わせた判断が必要になる
→
STEP 4
脱構築と再構築が起きる
古い戦略を捨て新しい最適化が生まれる
○○ネイティブ＝新技術を使う人ではなく、新しい前提で動く人
