# main-4-03 画像生成指示書: ベン図「暗黙知と形式知の両立」

## 1. このスライドが講義全体で果たす役割

### 講義の流れにおける位置

- **第3章（直前の章）** で「暗黙知に頼る開発は合理的だったが限界がある」と示した。特に 3-05 で暗黙知の4つの限界（チーム外に出せない、離脱で消える、スケールしない、AIに渡せない）を突きつけ、聴衆（特にベテラン）に「自分の経験が否定されるのか？」という不安を生んだ。
- **4-02（直前のスライド）** で「AIにより言語化コストが桁違いに下がった」ことを示し、「管理しないのが合理的」→「管理する方が合理的」という逆転を宣言した。
- **4-03（このスライド）** は、その逆転を **暗黙知を持つベテランにとっての朗報** として着地させる。「あなたの経験は消えない。AIが形式知を追加することで、あなたの経験の到達範囲が広がる」と伝える。
- **4-04（直後のスライド）** で好循環フライホイールへ進む。形式知化 → 良質コンテキスト → AI出力向上 → さらに効率化、という加速構造を示す。

### このスライドの感情的役割

第3章で生まれた **ベテランの防衛反応**（「暗黙知を否定するな」）を解除する最大の分岐点。ここで「置換（replacement）」ではなく「増幅（amplification）」として受け取られなければ、以降の提案が心理的に受け入れられない。

聴衆に与えたい感情は **「両取りできるのか」という安堵と興奮の同時発生**。

## 2. 現在のHTML実装の問題

現在はCSS（`.venn-circle`, `.venn-overlap`）でベン図を表現しているが:
- 2つの円の重なり具合がCSS制約で不自然
- 「暗黙知」「形式知」の対等な関係性が視覚的に弱い
- 重なり部分（＝拡張されたチーム能力）が小さすぎて「増幅」のインパクトが伝わらない
- 配色が設計書の指定（暗黙知=Comp系マゼンタ、形式知=Primary系グリーン）と異なる

## 3. 画像で表現すべきベン図の仕様

### 構図

2つの円が **横に並んで中央で重なる** 古典的なベン図。ただし重なり部分を **意図的にやや大きめ** にとる。理由は「増幅」のメッセージ：暗黙知と形式知は対立せず、重なる領域こそがチーム能力の拡張であることを視覚的に強調するため。

### 左の円: 暗黙知

- **ラベル**: 「暗黙知」（大きく）＋「人間の経験」（小さく補足）
- **背景色**: `#F5E0F2`（淡いマゼンタ / Comp-100）
- **ボーダー**: `#AA2896`（マゼンタ / Comp-600）、実線、やや太め
- **意図**: 「旧い側」「これまで頼ってきたもの」として配色体系上のコンプリメンタリ系を使う。ただし否定色ではなく、温かみのある色として扱う。このスライドでは「旧い＝悪い」ではなく「旧い＝これからも価値がある」というトーン。

### 右の円: 形式知

- **ラベル**: 「形式知」（大きく）＋「AIが読める」（小さく補足）
- **背景色**: `#D4EDDA`（淡いグリーン / Primary-100）
- **ボーダー**: `#28AA3C`（ブランドグリーン / Primary-600）、実線、やや太め
- **意図**: 「新しく獲得できるもの」「AIが扱える知識」としてプライマリ系を使う。暗黙知の円と同じサイズにすることで「置換ではなく追加」を表す。

### 重なり部分: 拡張されたチーム能力

- **ラベル**: 「拡張された」（1行目）＋「チーム能力」（2行目）
- **背景**: 左右の色が自然に混ざった領域（マゼンタとグリーンの重なり）
- **テキスト**: 太字、濃い色（`#1E352A` / Neutral-900）
- **意図**: この重なり部分が「このスライドの主役」。暗黙知も形式知も消えずに共存し、両方を持つことでチーム能力が拡張されるという構造を視覚的に示す。

### 全体の印象

- **白背景**に対してベン図が浮かぶシンプルな構図
- 装飾は最小限。円とラベルだけで語る
- テキストは日本語。フォントは太めのゴシック体
- フラットデザイン。影やグラデーションは使わない
- ベン図の下部には何も置かない（HTMLの3カード部分はHTML側で別途配置するため）

## 4. 配色体系（スライド全体のルール準拠）

この講義スライドでは以下の配色ルールが全体を貫いている。この画像もルールに従う:

| 系統 | 用途 | この図での使い方 |
|------|------|-----------------|
| Primary（グリーン系） | ポジティブな要素、強調 | 形式知の円 |
| Complementary（マゼンタ系） | 対比の「旧い側」 | 暗黙知の円（ただし否定ではない） |
| Neutral（グレー系） | テキスト、構造線 | ラベルテキスト |

重要: このスライドだけは、Comp系が「否定」ではなく「これまで価値を認めてきたもの」として使われる例外的な場面。暗黙知の円を暗くしたり、くすませたりしない。

## 5. 話者がこの画像を見せながら語る内容

> 「第3章で、暗黙知で回す仕組みは洗練された設計だと言いました。それは変わりません。ここで言っているのは、暗黙知を **残したまま**、形式知を **追加で** 獲得できるということです。
> 皆さんの20年の経験がAIを通じてチーム全体の力に変わる。経験が消えるのではなく、到達範囲が広がる。」

画像はこの語りの **視覚的アンカー** であり、「両方の円が消えずに重なっている」という構図そのものがメッセージになる。

## 6. 生成時の注意

- 画像サイズ: 1024x576（16:9、講義スライド標準）
- 日本語テキストの可読性を最優先。文字が小さすぎない、潰れない
- 円の内部にサブ項目（勘と判断力、文脈の理解...等）は入れない。ラベルのみ。詳細はHTML側のカードで補完する
- 写真やリアルなイラストは使わない。図形とテキストのみのインフォグラフィック
