### 1.2 テスト方針

- **テスト範囲**: 複数レイヤーを**実際に結合**して正しく動作することを検証する
- **DBの扱い**: H2インメモリDBを使い、テストごとに`@Transactional`でロールバック
- **単体テストとの違い**: 単体テストではモック化していたレイヤー間の連携を**実結合**で確認する

### 1.3 結合パターン

| パターン | 説明 | アノテーション |
|---------|------|---------------|
| Service + Mapper + DB | ビジネスロジックがDBと連携して正しく動作するか | `@SpringBootTest`, `@Transactional` |
| Controller + 全層 | REST APIがリクエスト→レスポンスまで一貫して動作するか | `@SpringBootTest`, `@AutoConfigureMockMvc`, `@Transactional` |
| 複数Service連携 | Service間の呼び出しが正しく連携するか | `@SpringBootTest`, `@Transactional` |

## 7. テスト環境

| ツール | 用途 |
|--------|------|
| JUnit 5 | テストランナー |
| Spring Boot Test | DIコンテナ・全層結合 |
| MockMvc | HTTPリクエストシミュレーション |
| H2 インメモリDB | テスト用DB |
| AssertJ | アサーション |

### 単体テストとの環境差異

| 項目 | 単体テスト | 結合テスト |
|------|----------|-----------|
| Mapper | H2 DB（`@MybatisTest`） | H2 DB（`@SpringBootTest`） |
| Service→Mapper | Mockito でモック | 実Mapperを使用 |
| Controller→Service | - | 実Service + 実Mapperを使用 |
| トランザクション | テストごとロールバック | テストごとロールバック |
