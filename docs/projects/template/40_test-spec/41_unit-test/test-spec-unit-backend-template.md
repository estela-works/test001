### 1.2 テスト方針

- **テスト範囲**: 各クラスを**独立して**検証する
- **依存の扱い**: 他レイヤーの依存は**モック化**する（Mapper層はH2で代替）

| Service層 | Mapper層をモック | `@ExtendWith(MockitoExtension.class)` |
