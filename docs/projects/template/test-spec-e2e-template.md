## 8. 実行手順

### 8.1 ローカル実行

```bash
# 依存パッケージインストール
npm install

# E2Eテスト実行
npx playwright test

# 特定のテストファイル実行
npx playwright test e2e/scenario-name.spec.ts

# UIモードで実行
npx playwright test --ui

# デバッグモードで実行
npx playwright test --debug
```

### 8.2 レポート確認

```bash
# HTMLレポート表示
npx playwright show-report
```
