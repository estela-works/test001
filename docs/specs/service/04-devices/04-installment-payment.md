# 分割払い仕様

ドコモの端末購入時における分割払いの仕様をまとめる。

---

## 通常分割払い

### 支払回数

| 支払回数 | 利用可能条件 |
|---------|------------|
| 12回 | 全端末対象 |
| 24回 | 全端末対象 |
| 36回 | 全端末対象 |

### 分割手数料

| 項目 | 内容 |
|------|------|
| 分割手数料 | **無料（金利0%）** |
| 頭金 | なし（一部店舗で設定される場合あり） |

### 月額計算

```
月額分割支払金 = 端末総額 / 支払回数
```

- 端数は1回目の支払いに含められる場合がある

---

## 残価設定型24回分割払い（いつでもカエドキプログラム用）

### 概要

いつでもカエドキプログラム（通常版・プラス版）で利用される特殊な分割方式。通常の均等分割とは異なり、24回目に残価（残存価格）が設定される。

### 月額計算

```
1～23回目の月額 = (端末総額 - 残価) / 23
24回目（残価額）= 端末返却で免除可能
```

### 通常分割との違い

| 項目 | 通常分割 | 残価設定型24回 |
|------|---------|-------------|
| 分割回数 | 12/24/36回 | 24回固定 |
| 各回の支払額 | 均等 | 1～23回は均等、24回目は残価 |
| 返却による免除 | なし | 24回目（残価）が免除 |
| 対象 | 全端末 | カエドキプログラム対象端末のみ |
| 所有権 | 完済後に取得 | 完済後に取得 |

---

## dポイント充当

端末購入時にdポイントを分割支払金に充当できる。充当方式は2種類あり、購入時に選択する。

### 充当方式の比較

| 項目 | 総額方式（均等充当） | 月々方式（月額上限充当） |
|------|-------------------|---------------------|
| 充当タイミング | 購入時に総額から差引 | 毎月の支払い時に充当 |
| 充当方法 | ポイントを均等に分割して各回に反映 | 月々の支払額を上限としてポイント充当 |
| 変更可否 | **選択後変更不可** | **選択後変更不可** |

### 充当方式の自動選択

| 購入チャネル | 自動選択される方式 |
|-------------|-----------------|
| ドコモオンラインショップ | 月々方式 |
| ahamoサイト | 月々方式 |
| ドコモショップ（店頭） | 選択可能 |

### 注意事項

- 充当方式は**購入時に1回のみ選択可能**で、後から変更できない
- dポイント（期間・用途限定）も充当可能（キャンペーンにより異なる場合あり）
- 残価設定型24回払いでもdポイント充当は利用可能

---

## 分割払いの一般的な注意事項

| 項目 | 内容 |
|------|------|
| 審査 | 分割払いには審査あり（10万円超は割賦販売法に基づく詳細審査） |
| 一括精算 | 残額を一括で支払うことが可能 |
| 回線解約時 | 分割支払金は回線解約後も継続して支払い |
| 端末変更時 | 旧端末の分割支払金が残っている場合は二重分割となる |
| 支払い方法 | クレジットカード、口座振替、請求書払い |

## 計算例

### 例: 端末総額 186,560円の場合

#### 通常分割（36回）

```
月額 = 186,560 / 36 = 5,182円/月（端数調整あり）
総支払額 = 186,560円
```

#### 残価設定型24回（残価 88,000円の場合）

```
1～23回目 = (186,560 - 88,000) / 23 = 4,285円/月（端数調整あり）
24回目 = 88,000円（返却で免除）
23か月目返却時の実質負担 = 4,285 x 23 = 98,555円
```
