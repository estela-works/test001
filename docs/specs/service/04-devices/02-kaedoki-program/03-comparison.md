# カエドキプログラム 通常版 vs プラス版 比較表

## 基本比較

| 項目 | 通常版 | プラス版 |
|------|--------|---------|
| 正式名称 | いつでもカエドキプログラム | いつでもカエドキプログラム＋ |
| 提供開始 | 2021年9月24日 | 2023年9月1日 |
| 分割方式 | 残価設定型24回払い | 残価設定型24回払い |
| 対象機種 | 通常対象機種 | プラス対象機種（通常対象機種とは異なる） |

## 加入条件比較

| 条件 | 通常版 | プラス版 |
|------|--------|---------|
| dポイントクラブ加入 | 必須 | 必須 |
| 残価設定型24回払い | 必須 | 必須 |
| smartあんしん補償 | **不要（任意）** | **必須（継続加入）** |
| ドコモ回線契約 | 不要 | 不要 |
| ドコモMAX / eximo | 不要 | 不要 |

## 特典比較

| 返却タイミング | 通常版 | プラス版 |
|--------------|--------|---------|
| 12か月目 | 対象外 | **残り全額免除（早期利用料あり）** |
| 13〜22か月目 | 一部割引（早期利用特典） | **残り全額免除（早期利用料あり）** |
| 23か月目 | 残価免除 | 残価免除 |
| 24か月目以降 | 残価を24回再分割 | 残価を24回再分割 |

## コスト比較

| 項目 | 通常版 | プラス版 |
|------|--------|---------|
| 月額追加費用 | なし | smartあんしん補償（330〜1,720円/月） |
| 早期利用料 | なし | 5,500〜12,100円 |
| 故障時利用料（補償あり） | 2,200円 | 2,200円 |
| 故障時利用料（補償なし） | 22,000円 | （補償解除で＋特典失効のためケース限定的） |

## 選択指針

### 通常版が向いているケース

- 23か月目での返却を想定している
- smartあんしん補償の月額費用を抑えたい
- 端末を長期間使用する可能性がある

### プラス版が向いているケース

- 1年程度の短期サイクルで端末を変更したい
- 最新機種を常に使いたい
- smartあんしん補償の補償サービスも活用したい
