# いつでもカエドキプログラム＋（プラス版）

## 正式名称

**いつでもカエドキプログラム＋**（全角プラス「＋」を使用）

## 提供開始日

2023年9月1日

## サービス内容

「いつでもカエドキプログラム（プラス対象機種）」と「smartあんしん補償」の**両方に加入・継続**することで、最短**12か月目**から端末を返却でき、返却時点以降の分割支払金および残価が免除される仕組み。

> 独立したサービスではなく、「いつでもカエドキプログラム」＋「smartあんしん補償」の組み合わせで自動適用される特典。

## 加入条件

| 条件 | 必須/任意 |
|------|----------|
| dポイントクラブ加入 | **必須** |
| プラス対象機種を残価設定型24回払いで購入 | **必須** |
| 購入時にプログラムへ加入 | **必須** |
| **smartあんしん補償に加入・継続** | **必須** |
| ドコモ回線契約 | **不要** |
| 特定の料金プラン | **不要** |

### smartあんしん補償の判定条件

- プログラム利用申込日が属する月から遡って**2か月以内**に、対象機種を登録電話機とするsmartあんしん補償の契約があること
- 当社システムによって自動判定される
- **持込機種**でsmartあんしん補償を契約した場合はプラス利用**不可**

## 返却タイミングと特典

| 返却タイミング | 特典内容 |
|--------------|---------|
| 12か月目まで | 13〜23回目の分割支払金 + 24回目残価が**全額免除** |
| 13〜22か月目 | 翌月以降の分割支払金 + 残価が免除 |
| 23か月目 | 24回目残価のみ免除（通常版と同じ） |

## 早期利用料

12〜22か月目の早期返却には「いつでもカエドキプログラム＋早期利用料」の支払いが必要。

| 条件 | 金額 |
|------|------|
| 早期利用料 | 5,500〜12,100円（税込・機種により異なる） |

## smartあんしん補償解除時の影響

### 解除後の猶予期間

smartあんしん補償を解約しても、**解約日の翌々月末まで**にプログラム＋の利用申し込みをすれば適用される。

### 返却時の判定ルール

返却時点でsmartあんしん補償が未加入でも、**返却日の前々月1日から前日までの期間**に補償サービスを契約していた実績があれば「加入あり」として判定される。

### 機種変更後の特例

次機種に機種変更した後、変更前の対象機種についてプログラム＋利用を希望する場合は、次機種変更後の**翌々月末まで**に利用申し込みをすれば、smartあんしん補償を解約済みでもプログラム＋の利用が可能。

## 通常版との主な違い

| 項目 | 通常版 | プラス版 |
|------|--------|---------|
| 最短返却可能月 | 13か月目（早期利用特典） | **12か月目** |
| smartあんしん補償 | 任意 | **必須** |
| 早期利用料 | なし | **5,500〜12,100円** |
| 早期返却時の免除範囲 | 一部割引のみ | **残り全額免除** |
