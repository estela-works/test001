# ドコモMAX - カエドキプログラムとの関連

## 加入条件としての関連

**ドコモMAXは、いつでもカエドキプログラム（通常版・プラス版いずれも）の加入条件に含まれていない。**

- カエドキプログラムは料金プランに依存しない
- dポイントクラブに加入していれば利用可能
- ドコモ回線契約自体が不要
- ahamo契約者や回線を持たないdアカウントユーザーでも利用可能

## システム上の関連

共有された要件情報によると、以下の場面でドコモMAXが条件判定に使用される:

1. **支払方法の自動調整**: カエドキ（通常）対象機種選択時に、smartあんしん補償未選択**かつ**ドコモMAX未選択の場合は通常分割にする制御
2. **確認モーダル表示**: カエドキPG加入中かつドコモMAX未選択の場合、smart補償解除時に確認モーダルを表示

> ドコモMAXはカエドキプログラムの「加入条件」ではないが、オンラインショップの画面制御においては条件判定に使用される関係にある。
