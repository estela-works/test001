# いつでもカエドキプログラム（通常版）

## 正式名称

**いつでもカエドキプログラム**（商標登録済み・TM表記あり）

## 提供開始日

2021年9月24日

## サービス内容

対象スマートフォン・タブレットを「残価設定型24回分割払い」で購入し、23か月目までに返却することで、24回目（残価額）の分割支払金の支払いが不要になる端末購入サポートプログラム。

## 加入条件

| 条件 | 必須/任意 |
|------|----------|
| dポイントクラブ加入（またはドコモビジネスメンバーズ） | **必須** |
| 対象機種を残価設定型24回払いで購入 | **必須** |
| 購入時にプログラムへ加入 | **必須** |
| dポイントクラブを継続し対象機種を返却 | **必須** |
| 返却時に未払金がないこと | **必須** |
| 端末が正常動作状態であること | **必須** |
| ドコモ回線契約 | **不要** |
| 特定の料金プラン（eximo、ドコモMAX等） | **不要** |
| smartあんしん補償 | **不要（任意）** |

> **重要**: ドコモ回線契約は不要。dアカウントさえあれば回線契約なしで加入できる。

## 返却タイミングと特典

| 返却タイミング | 特典内容 |
|--------------|---------|
| 1〜12か月目 | 早期利用特典なし（23か月目までの残りの分割金は継続支払い） |
| 13〜22か月目 | 早期利用特典（翌月以降の分割支払金を一部割引） |
| 23か月目 | 24回目の残価のみ免除（最も標準的なタイミング） |
| 24か月目以降 | 残価が自動的に24回に再分割される |

## 返却時の故障時利用料

| smartあんしん補償加入状態 | 故障時利用料 |
|-------------------------|------------|
| 加入中 | 2,200円（税込） |
| 未加入 | 22,000円（税込） |

> smartあんしん補償は必須ではないが、加入していると返却時の故障時利用料が大幅に軽減される。

## 2026年3月5日以降の変更点

2026年3月5日以降に**新規加入**した場合、端末返却時に最大**22,000円（税込）のプログラム利用料**が発生する。

### プログラム利用料の免除条件

「**ドコモで買替えおトク割**」の条件を満たす場合、利用料が免除される。

- ドコモで次の対象機種を購入すること
- 購入から31日以内に同一名義で返却すること

> 2026年3月4日以前の加入者には変更は適用されない。

## 注意事項

- dポイント充当時は「総額方式」と「月々方式」の2種類から選択可能（選択後変更不可）
- ドコモオンラインショップ・ahamoサイトでは「月々方式」が自動選択される
- 23か月目以降も端末を継続利用する場合、手続き不要で残価が自動的に24回に再分割される
