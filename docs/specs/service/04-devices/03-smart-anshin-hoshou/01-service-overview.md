# smartあんしん補償 サービス概要

## 正式名称

**smartあんしん補償**

## サービス内容

故障・破損・水濡れ・盗難・紛失など幅広いトラブルに対応する端末補償サービス。

## 基本情報

| 項目 | 内容 |
|------|------|
| 交換対応 | 交換電話機（リフレッシュ品）との交換（年間最大2回） |
| 交換所要期間 | 最短翌日〜2日 |
| Web申込割引 | 交換利用料が10%割引 |
| 加入期限 | 対象機種の購入日から14日以内（2022年9月15日以降発売機種） |

## 月額料金

機種によって異なる。

| 区分 | 月額（税込） |
|------|------------|
| 一般機種 | 330円〜1,720円 |
| ドコモ認定品（Certified） | 550円 |

## 付帯サービス

| サービス | 内容 |
|---------|------|
| 家財保険（家電補償） | 家電製品のトラブル補償 |
| 不正決済補償 | 上限100万円 |
| 携行品保険 | 外出先での荷物破損 |
| dカード特典 | dカードプラチナで最大11,000ポイント還元 |
