# 端末購入割引キャンペーン

ドコモの端末購入時に適用可能な割引キャンペーンの仕様をまとめる。

---

## 1. 5G WELCOME割

### 概要

MNP（他社からの乗り換え）または新規契約時に、対象5G端末の購入代金を割引するキャンペーン。

### 対象条件と割引額

| 項目 | 内容 |
|------|------|
| 対象契約 | MNP（他社からの乗り換え）、新規契約 |
| 割引額 | 最大44,000円（税込）（機種により異なる） |
| 割引形態 | 端末代金からの直接割引、またはdポイント還元 |
| 対象端末 | 5G対応スマートフォン・タブレット（対象機種は時期により変動） |

### 注意事項

- 機種変更は対象外
- 割引額は機種ごとに異なるため、申込時に確認が必要
- 他の割引キャンペーンとの併用可否は個別に確認が必要

---

## 2. 端末購入割引

### 概要

機種変更または契約変更時に、対象端末の購入代金を割引するキャンペーン。

### 対象条件と割引額

| 項目 | 内容 |
|------|------|
| 対象契約 | 機種変更、契約変更 |
| 割引額 | 最大23,650円（税込）（機種により異なる） |
| 利用条件 | 利用期間12か月以上 |
| 割引形態 | 端末代金からの直接割引 |

### 注意事項

- 新規契約・MNPは対象外（5G WELCOME割が適用される）
- 利用期間12か月未満の場合は対象外
- 対象機種は定期的に更新される

---

## 3. オンラインおトク割

### 概要

ドコモオンラインショップ限定で適用される端末購入割引。

### 対象条件と割引額

| 項目 | 内容 |
|------|------|
| 対象チャネル | **ドコモオンラインショップ限定** |
| 割引額 | 3,300円～44,000円（税込）（機種により異なる） |
| 対象契約 | 新規契約、MNP、機種変更（機種によって異なる） |
| 割引形態 | 端末代金からの直接割引 |

### 注意事項

- ドコモショップ（店頭）では利用不可
- ahamoサイトでの購入も対象になる場合がある
- 割引額の幅が広いため、機種ごとに確認が必要

---

## 4. オンライン限定 機種購入割引

### 概要

ドコモオンラインショップでのみ提供される機種限定の購入割引。

### 対象条件

| 項目 | 内容 |
|------|------|
| 対象チャネル | **ドコモオンラインショップ限定** |
| 対象機種 | 限定機種のみ（時期により変動） |
| 割引形態 | 端末代金からの直接割引 |

### 注意事項

- 店舗（ドコモショップ、家電量販店等）では利用不可
- 対象機種・割引額は随時変更される

---

## 5. ドコモで買替えおトク割（2026年3月5日新設）

### 概要

2026年3月5日から新設されたキャンペーン。いつでもカエドキプログラムのプログラム利用料（最大22,000円）を免除する。

### 対象条件

| 項目 | 内容 |
|------|------|
| 適用条件1 | ドコモで次の対象端末を購入すること |
| 適用条件2 | 購入から31日以内に同一名義で旧端末を返却すること |
| 免除対象 | いつでもカエドキプログラムのプログラム利用料（最大22,000円） |

### カエドキプログラムとの関係

```
プログラム利用料（最大22,000円） - ドコモで買替えおトク割 = 0円（免除）
```

### 注意事項

- 2026年3月5日以降に新規加入したカエドキプログラム加入者が対象
- 2026年3月4日以前の加入者にはプログラム利用料自体が発生しないため本割引は不要
- 「ドコモで次の端末を買う」ことが条件のため、他社への乗り換え時には免除されない

## 割引キャンペーン比較表

| キャンペーン | 対象契約 | 最大割引額 | チャネル | 主な条件 |
|------------|---------|----------|---------|---------|
| 5G WELCOME割 | MNP・新規 | 44,000円 | 全チャネル | 5G対応端末 |
| 端末購入割引 | 機種変更・契約変更 | 23,650円 | 全チャネル | 利用12か月以上 |
| オンラインおトク割 | 新規・MNP・機変 | 44,000円 | オンライン限定 | 機種により異なる |
| オンライン限定機種購入割引 | 各種 | 機種による | オンライン限定 | 限定機種のみ |
| ドコモで買替えおトク割 | カエドキ利用者 | 22,000円免除 | 全チャネル | 31日以内に返却 |

---

## 割引適用の判断フロー

```
1. 契約種別を確認
   ├─ MNP/新規 → 5G WELCOME割を確認
   └─ 機種変更/契約変更 → 端末購入割引を確認（利用12か月以上か）

2. 購入チャネルを確認
   ├─ オンラインショップ → オンラインおトク割、オンライン限定機種購入割引も確認
   └─ 店舗 → オンライン限定割引は対象外

3. カエドキプログラム利用の場合（2026/3/5以降加入）
   └─ ドコモで買替えおトク割の条件を確認
```
