# 端末購入プログラム一覧

ドコモが提供する端末購入プログラムの仕様をまとめる。

---

## 1. いつでもカエドキプログラム（通常版）

### 概要

残価設定型24回分割払いで対象端末を購入し、23か月目までに返却することで24回目（残価額）の支払いが免除されるプログラム。

### 対象端末

| カテゴリ | 例 |
|---------|-----|
| iPhone | iPhone 16シリーズ等 |
| Android | Galaxy、Xperia、AQUOS等 |
| iPad | iPad Pro、iPad Air等 |
| タブレット | dtab等 |
| 5G対応PC | ASUS等 |

### 月額計算

```
月額分割支払金 = (端末総額 - 残価) / 23
```

- 1回目～23回目: 上記の月額を支払い
- 24回目: 残価額（返却により免除可能）

### 返却タイミングと特典

| 返却タイミング | 特典内容 |
|--------------|---------|
| 1～22か月目 | 早期利用特典: 返却翌月～23回目まで毎月50円～1,200円割引 |
| 23か月目 | 24回目の残価が免除（標準的な利用パターン） |
| 24か月目以降 | 残価が自動的に24回に再分割（手続き不要） |

### 返却条件

返却端末は以下の全条件を満たす必要がある。

| 条件 | 詳細 |
|------|------|
| 故障なし | 正常動作すること |
| 水濡れなし | 水没判定シールが反応していないこと |
| 外観破損なし | 筐体の著しい破損がないこと |
| 画面割れなし | ディスプレイにひび割れがないこと |
| データ消去済み | 初期化済みであること |
| 改造なし | root化、脱獄等の改造がないこと |
| 未払いなし | 分割支払金に未払いがないこと |

### 故障時利用料

| smartあんしん補償 | 故障時利用料（税込） |
|-----------------|-------------------|
| 加入中 | 2,200円 |
| 未加入 | 22,000円 |

### 2026年3月5日以降の変更点（プログラム利用料の新設）

2026年3月5日以降に新規加入した場合、端末返却時にプログラム利用料が発生する。

| 項目 | 内容 |
|------|------|
| プログラム利用料 | 最大22,000円（税込） |
| 免除条件 | 「ドコモで買替えおトク割」適用時 |
| 免除の具体条件 | ドコモで次の対象端末を購入 + 購入から31日以内に旧端末を返却 |
| 既存加入者への影響 | 2026年3月4日以前の加入者は従来条件のまま（変更なし） |

## 2. いつでもカエドキプログラム＋

### 概要

いつでもカエドキプログラムの上位版。12～22か月目に早期返却することで、13～23回目の分割支払金および24回目の残価が全額免除される。smartあんしん補償への加入・継続が必須条件。

### 必須条件

| 条件 | 詳細 |
|------|------|
| smartあんしん補償 | 加入かつ継続が**必須** |
| 支払方式 | 残価設定型24回分割払い |

### smartあんしん補償 月額

| 月額（税込） | 備考 |
|-------------|------|
| 330円～1,720円 | 端末により異なる |

### 月額計算

```
月額支払額 = (端末総額 - 残価) / 23 + smartあんしん補償月額
```

### 早期利用料

12～22か月目に返却する際、早期利用料が1回発生する。

| smartあんしん補償プラン月額 | 早期利用料（税込） |
|--------------------------|-------------------|
| 330円 / 490円 | 5,500円 |
| 605円 / 860円 | 8,250円 |
| 880円～1,720円 | 12,100円 |

### 12か月返却時の実質負担計算

```
実質負担額 = (月額分割支払金 x 12) + (smartあんしん補償月額 x 12) + 早期利用料
```

### 早期返却時の免除内容

| 項目 | 内容 |
|------|------|
| 12～22か月目返却時 | 13～23回目の分割支払金 + 24回目残価 = 全額免除 |
| 発生費用 | 早期利用料のみ |

## 3. スマホおかえしプログラム

### 概要

36回分割払いで購入した端末を返却することで、最大12回分（最終12回分）の分割支払金が免除されるプログラム。端末代金の最大1/3が免除される。

### 現在の状況

| 項目 | 内容 |
|------|------|
| 新規対象機種 | なし（いつでもカエドキプログラム開始以降、新規追加なし） |
| 既存加入者 | 35か月目の月末まで利用申込可能 |

### 計算

```
免除額 = 端末総額 / 36 x 12  （最大12回分）
実質負担額 = 端末総額 / 36 x 24（最大24回分の支払い）
```

---

## プログラム比較表

| 項目 | カエドキ通常版 | カエドキプラス版 | スマホおかえし |
|------|-------------|---------------|-------------|
| 分割回数 | 24回（残価設定型） | 24回（残価設定型） | 36回 |
| 最適返却月 | 23か月目 | 12～22か月目 | 25か月目 |
| 最大免除額 | 残価額 | 13～23回目+残価 | 最大12回分（1/3） |
| smartあんしん補償 | 任意 | **必須** | 任意 |
| 早期利用料 | なし | 5,500～12,100円 | なし |
| プログラム利用料（2026/3/5～） | 最大22,000円 | 最大22,000円 | なし |
| 新規受付 | あり | あり | なし（既存のみ） |

---

## 注意事項

- いつでもカエドキプログラムはドコモ回線契約が不要（dアカウントのみで加入可）
- dポイント充当は「総額方式」と「月々方式」から選択可能（選択後変更不可）
- 2026年3月5日以降のプログラム利用料は通常版・プラス版の両方に適用される
- スマホおかえしプログラムは新規対象機種の追加がなく、実質的に終了へ向かっている
