## 見積もり時のカテゴリ分類

アクセサリーを見積もりに含める際は、以下の優先度で分類する。

### 必須級（端末購入時にほぼ必ず必要）

| カテゴリ | 推定費用（税込） | 理由 |
|---------|----------------|------|
| ケース | 2,000～4,000円 | 端末保護のため必須。機種専用品を推奨 |
| 保護フィルム | 1,500～3,000円 | 画面保護のため必須。ガラスフィルムが主流 |

```
必須級合計目安 = 3,500～7,000円
```

### 推奨（同時購入が望ましい）

| カテゴリ | 推定費用（税込） | 理由 |
|---------|----------------|------|
| 充電機器（ACアダプタ） | 1,500～3,000円 | 最近の端末は充電器が同梱されないため |
| ケーブル | 1,000～1,500円 | USB-Cケーブルが別売りの場合 |

```
推奨合計目安 = 2,500～4,500円
```

### オプション（ユーザーの用途に応じて提案）

| カテゴリ | 推定費用（税込） | ユースケース |
|---------|----------------|------------|
| モバイルバッテリー | 3,000～8,000円 | 外出が多いユーザー |
| イヤホン（ワイヤレス） | 5,000～30,000円 | 通勤・音楽利用 |
| 車載ホルダー・充電器 | 2,000～5,000円 | 車通勤ユーザー |
| スマートウォッチ | 10,000～50,000円 | 健康管理・通知確認 |
| 外部メモリ（microSD） | 1,000～3,000円 | 写真・動画の保存用（対応機種のみ） |

## 見積もり計算式

### 最小構成（必須級のみ）

```
アクセサリー費用（最小） = ケース + 保護フィルム
                        = 約 3,500～7,000円
```

### 標準構成（必須級 + 推奨）

```
アクセサリー費用（標準） = ケース + 保護フィルム + 充電器 + ケーブル
                        = 約 6,000～11,500円
```

### フル構成（標準 + オプション）

```
アクセサリー費用（フル） = 標準 + モバイルバッテリー + イヤホン + 車載アクセサリー
                        = 約 16,000～54,500円
```

## 支払い・購入に関する注意事項

| 項目 | 内容 |
|------|------|
| 支払方式 | **一括払いが基本**（分割プログラム対象外） |
| dポイント | dポイントでの購入可能 |
| 送料 | オンラインショップでは送料無料が多い |
| 店頭購入 | ドコモショップ・家電量販店で購入可能 |
| 端末との同時購入 | 端末購入時にまとめて購入可能（別会計） |

## 見積もり作成時のポイント

1. **充電器の同梱有無を必ず確認** -- 最近の端末（iPhone 12以降、多くのAndroid）は充電器が同梱されない。初めてスマートフォンを使うユーザーには充電器を必ず見積もりに含める
2. **ケース・フィルムは機種確定後に選定** -- 機種によってサイズが異なるため、端末確定前に具体的な商品を選定しない
3. **アクセサリーは端末代金とは別会計** -- カエドキプログラム等の分割対象にはならない点を説明する
4. **dポイント利用の案内** -- 端末購入でポイントを使い切らず、アクセサリー購入に充当する選択肢も案内する
