# ドコモ光

NTTドコモが提供する光回線インターネット接続サービス。フレッツ光回線を利用した光コラボレーションモデル。

---

## 月額料金

### 1ギガプラン（2年定期契約/税込）

| タイプ | マンション | 戸建て |
|---|---|---|
| タイプA | 4,400円 | 5,720円 |
| タイプB | 4,620円 | 5,940円 |
| タイプC | 4,400円 | 5,720円 |
| 単独タイプ | 4,180円 | 5,500円 |

※定期契約なしの場合: マンション +1,100円 / 戸建て +1,650円

### 10ギガプラン（2年定期契約/税込/マンション・戸建て共通）

| タイプ | 月額料金 |
|---|---|
| タイプA | 6,380円 |
| タイプB | 6,600円 |
| 単独タイプ | 5,940円 |

※定期契約なしの場合: +1,650円

### プロバイダ区分

| タイプ | 主なプロバイダ | 備考 |
|---|---|---|
| タイプA（安価） | GMOとくとくBB、OCNインターネット、@nifty、ドコモnet、plala 等（約17社） | - |
| タイプB（+220円） | @T COM、TNC、AsahiNet 等（約6社） | タイプAより月額220円高い |

---

## 注意事項

- タイプA/Bの違いはプロバイダの選択肢であり、回線品質に差はない
- タイプCはケーブルテレビの設備を利用する形態
- 単独タイプは別途プロバイダ契約が必要（プロバイダ料金が別途発生）
- 10ギガプランは対応エリアが限定的であり、申込前にエリア確認が必要
- 新規工事費無料キャンペーンは終了時期未定（公式サイトで要確認）
- home 5G のセット割とドコモ光セット割は併用不可
