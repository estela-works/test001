## 採番の考え方

1. ドコモ光 → セット割の主軸（割引額最大）
2. home 5G → ドコモ光の代替（併用不可）
3. ドコモでんき → でんきセット割に関連
4. ドコモガス → でんきとのセット特典

## サービス間の関係

- **ドコモでんき + ドコモガス**: ガスセット特典として電気のdポイント還元率が+2%アップ
- **ドコモ光 + ドコモスマホ**: セット割引（最大-1,210円/月）が適用可能
- **home 5G + ドコモスマホ**: セット割引あり。ただしドコモ光セット割とは併用不可
