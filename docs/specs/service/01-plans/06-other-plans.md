# その他プラン

特定の条件やユーザー層を対象とした料金プラン。

---

## はじめてスマホプラン

FOMAからの契約変更、または他社3Gケータイからの乗り換えユーザーを対象とした移行支援プラン。

### 月額基本料金

| 項目 | 内容 |
|------|------|
| 月額料金 | 1,980円（税込） |
| データ容量 | 1GB |

### 割引適用後料金

| 条件 | 月額料金（税込） |
|------|-----------------|
| 各種割引適用後最安 | 1,078円 |

### 通話料

| 項目 | 料金（税込） |
|------|-------------|
| 5分以内国内通話 | 無料（標準付帯） |
| 5分超過分 | 22円/30秒 |

### 対象者

- FOMA（3G）からの契約変更ユーザー
- 他社3Gケータイからの乗り換え（MNP）ユーザー

### 注意事項

- **FOMA（3G）サービス終了日: 2026年3月31日** に伴い、申込期限あり
- FOMA終了後は新規申込不可となる可能性がある
- データ容量超過後は速度制限がかかる

## U15はじめてスマホプラン

15歳以下の利用者を対象としたプラン。成長に合わせた容量設定。

### 月額基本料金

| データ容量 | 割引適用後月額（税込） |
|-----------|----------------------|
| 5GB | 1,628円 |
| 10GB | 2,508円 |

### 通話料

| 項目 | 料金（税込） |
|------|-------------|
| 5分以内国内通話 | 無料（標準付帯） |
| ファミリー割引グループ内通話 | 24時間無料 |
| 5分超過分（グループ外） | 22円/30秒 |

### 対象者

- **15歳以下**の利用者

### 年齢到達後のデータ容量変更

19歳の誕生月を過ぎると、翌月からデータ容量が減少する。

| 現在の容量 | 19歳到達後の容量 |
|-----------|-----------------|
| 5GB | 1GB |
| 10GB | 2GB |

### 注意事項

- 契約者（保護者）と利用者（15歳以下）は異なる場合がある
- 19歳到達後のデータ容量減少に注意が必要
- 必要に応じて他プランへの変更を検討すること

## キッズケータイプラン

12歳以下の子ども向け。通話とメッセージに特化したシンプルなプラン。

### 月額基本料金

| 項目 | 内容 |
|------|------|
| 月額料金 | 550円（税込） |

### 通話料

| 項目 | 料金（税込） |
|------|-------------|
| ファミリー割引グループ内通話 | 無料 |
| グループ外通話 | 22円/30秒 |

### 対象者

- **12歳以下**の利用者

### データ通信

- インターネット接続（ブラウジング、アプリ等）は**利用不可**
- **メッセージ送受信のみ**対応

### 対応機種

| 機種名 | 備考 |
|--------|------|
| SK-41D | - |
| KY-41C | - |
| SH-03M | - |

### 注意事項

- キッズケータイ専用機種でのみ利用可能（一般のスマートフォンでは利用不可）
- データ通信はメッセージに限定されるため、Webブラウジングやアプリの利用はできない
- GPS等の見守り機能は機種により対応状況が異なる
