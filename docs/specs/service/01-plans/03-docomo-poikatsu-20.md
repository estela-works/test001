# ドコモ ポイ活 20

20GBと無制限の2段階制にポイント還元を付加したプラン。dカード・d払い利用でdポイントが貯まる。

## 月額基本料金

| データ利用量 | 月額料金（税込） |
|-------------|-----------------|
| 20GBまで | 7,898円 |
| 20GB超～無制限 | 9,570円 |

## 適用可能な割引

ドコモMAXと同様の割引体系が適用される。

| 割引名 | 条件 | 割引額（税込） |
|--------|------|---------------|
| みんなドコモ割 | 3回線以上 | -1,210円 |
| みんなドコモ割 | 2回線 | -550円 |
| 長期利用割 | 20年以上 | -220円 |
| 長期利用割 | 10年以上 | -110円 |
| dカードお支払割 | dカード PLATINUM / GOLD / GOLD U | -550円 |
| dカードお支払割 | dカード（通常） | -220円 |
| ドコモ光セット割 / home 5G セット割 | ドコモ光またはhome 5G契約 | -1,210円 |
| ドコモでんきセット割 | ドコモでんき契約 | -110円 |

## ポイント還元

| 利用方法 | 還元内容 |
|----------|---------|
| dカード / d払い利用 | 最大6%相当のdポイント |
| ポイント上限 | 2,500ポイント/月 |

## 通話料・通話オプション

| 項目 | 料金（税込） |
|------|-------------|
| 家族間通話 | 無料 |
| 国内通話（家族以外） | 22円/30秒 |
| 5分通話無料オプション | 880円/月 |
| かけ放題オプション | 1,980円/月 |

## データ容量

- データ利用量: **20GB / 無制限の2段階制**
- 20GB超過時は自動的に無制限段階の料金が適用される

## その他の特典

- Amazonプライム最大6か月間追加料金なし

## 注意事項

- ポイント還元率はdカードの種類・d払いの利用状況により異なる
- ポイント還元上限は月あたり2,500ポイント
- 20GBを超えた場合は自動的に上位の料金段階に移行する（速度制限ではない）
- 実質料金はポイント還元を料金に充当した場合の目安
