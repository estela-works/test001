# ドコモ ポイ活 MAX

データ無制限にポイント還元を強化したプラン。dカード・d払い利用で大幅なポイント還元が受けられる。

## 月額基本料金

| プラン | 月額料金（税込） |
|--------|-----------------|
| ドコモ ポイ活 MAX | 11,748円 |

## 適用可能な割引

ドコモMAXと同様の割引が適用可能。

| 割引名 | 条件 | 割引額（税込） |
|--------|------|---------------|
| みんなドコモ割 | 3回線以上 | -1,210円 |
| みんなドコモ割 | 2回線 | -550円 |
| 長期利用割 | 20年以上 | -220円 |
| 長期利用割 | 10年以上 | -110円 |
| dカードお支払割 | dカード PLATINUM / GOLD / GOLD U | -550円 |
| dカードお支払割 | dカード（通常） | -220円 |
| ドコモ光セット割 / home 5G セット割 | ドコモ光またはhome 5G契約 | -1,210円 |
| ドコモでんきセット割 | ドコモでんき契約 | -110円 |

## ポイント還元

| 利用方法 | 最大還元率 |
|----------|----------|
| dカード利用 | 最大10.0%（PLATINUM） |
| d払い利用 | 最大7.0% |

### ポイント充当後の実質料金

- ポイント充当後実質最安: **約2,948円/月**

## 通話料・通話オプション

| 項目 | 料金（税込） |
|------|-------------|
| 家族間通話 | 無料 |
| 国内通話（家族以外） | 22円/30秒 |
| 5分通話無料オプション | 880円/月 |
| かけ放題オプション | 1,980円/月 |

## データ容量

- データ利用量: **無制限**
- テザリング: **無料**
- 国際ローミング: **30GBまで無料**

## 選べる特典

毎月2つまで追加料金0円で選択可能:

- Lemino
- dアニメストア
- DAZN for docomo
- NBA docomo

## その他の特典

- Amazonプライム最大6か月割引

## 注意事項

- ポイント還元率はdカードの種類により異なる
- ポイント還元には月額料金のdカード支払い等の条件がある
- 実質料金はポイント還元を料金に充当した場合の目安であり、利用状況により変動する
- 還元されるdポイントには上限がある場合がある
