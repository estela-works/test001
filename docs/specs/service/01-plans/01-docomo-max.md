# ドコモ MAX

データ無制限の大容量プラン。利用量に応じた3段階制の料金体系。eximoの後継プラン。

## 月額基本料金

| データ利用量 | 月額料金（税込） |
|-------------|-----------------|
| 1GB以下 | 5,698円 |
| 1GB超～3GB | 6,798円 |
| 3GB超～無制限 | 8,448円 |

## 適用可能な割引

| 割引名 | 条件 | 割引額（税込） |
|--------|------|---------------|
| みんなドコモ割 | 3回線以上 | -1,210円 |
| みんなドコモ割 | 2回線 | -550円 |
| 長期利用割 | 20年以上 | -220円 |
| 長期利用割 | 10年以上 | -110円 |
| dカードお支払割 | dカード PLATINUM / GOLD / GOLD U | -550円 |
| dカードお支払割 | dカード（通常） | -220円 |
| ドコモ光セット割 / home 5G セット割 | ドコモ光またはhome 5G契約 | -1,210円 |
| ドコモでんきセット割 | ドコモでんき契約 | -110円 |

## 割引適用後の最安料金

全割引を最大適用した場合（みんなドコモ割3回線以上 + 長期利用割20年以上 + dカードPLATINUM/GOLD/GOLD U + ドコモ光セット割 + ドコモでんきセット割）:

| データ利用量 | 割引後月額（税込） |
|-------------|-------------------|
| 1GB以下 | 2,398円 |
| 1GB超～3GB | 3,498円 |
| 3GB超～無制限 | 5,148円 |

## 通話料・通話オプション

| 項目 | 料金（税込） |
|------|-------------|
| 家族間通話 | 無料 |
| 国内通話（家族以外） | 22円/30秒 |
| 5分通話無料オプション | 880円/月 |
| かけ放題オプション | 1,980円/月 |

## データ容量

- データ利用量: **無制限**（3段階制料金）
- テザリング: **無料**
- 国際ローミング: **30GBまで無料**

## 選べる特典

毎月2つまで追加料金0円で選択可能:

- Lemino
- dアニメストア
- DAZN for docomo
- NBA docomo

## その他の特典

- Amazonプライム最大6か月割引

## 注意事項

- 料金は利用したデータ量に応じて3段階で自動的に決定される
- 割引は条件を満たしている間のみ適用
- 長期利用割は対象回線の契約期間に基づく
