# ドコモ mini

低容量・低価格の料金プラン。4GBと10GBの2つのデータ容量から選択可能。irumoの後継プラン。

## 月額基本料金

| データ容量 | 月額料金（税込） |
|-----------|-----------------|
| 4GB | 2,750円 |
| 10GB | 3,850円 |

## 適用可能な割引

| 割引名 | 条件 | 割引額（税込） |
|--------|------|---------------|
| dカードお支払割 | dカード PLATINUM / GOLD / GOLD U | -550円 |
| dカードお支払割 | dカード（通常） | -220円 |
| ドコモ光セット割 / home 5G セット割 | ドコモ光またはhome 5G契約 | -1,210円 |
| ドコモでんきセット割 | ドコモでんき契約 | -110円 |

## 割引適用後の最安料金

全割引を最大適用した場合（dカードPLATINUM/GOLD/GOLD U + ドコモ光セット割 + ドコモでんきセット割）:

| データ容量 | 割引後月額（税込） |
|-----------|-------------------|
| 4GB | 880円 |
| 10GB | 1,980円 |

## 通話料・通話オプション

| 項目 | 料金（税込） |
|------|-------------|
| 国内通話 | 22円/30秒 |
| 5分通話無料オプション | 880円/月 |
| かけ放題オプション | 1,980円/月 |

## データ容量・超過時の制限

| 項目 | 内容 |
|------|------|
| データ容量 | 4GB または 10GB |
| 超過後の通信速度 | 最大128kbps |
| データ追加購入 | 1GB あたり 1,100円 |

## 注意事項・対象外事項

### みんなドコモ割について

- **割引対象外**（ドコモ miniは割引を受けられない）
- ただし、ファミリー割引グループの**カウント対象にはなる**（他の家族回線の割引には貢献する）

### 家族間通話について

- **家族間通話無料は適用されない**
- 家族への通話も22円/30秒の通常料金が発生する

### ドコモメールについて

- ドコモメール（@docomo.ne.jp）は**標準では利用不可**
- 利用するには別途オプション契約が必要

### その他

- 長期利用割は対象外
- テザリングは利用可能（データ容量に含まれる）
