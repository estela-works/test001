# ahamo

NTTドコモのオンライン専用プラン。シンプルな料金体系と5分以内国内通話無料が特徴。

## プラン一覧

| プラン | データ容量 | 月額料金（税込） |
|--------|-----------|-----------------|
| ahamo（基本） | 30GB | 2,970円 |
| ahamo大盛り | 110GB（30GB + 80GB） | 4,950円 |
| ahamoポイ活 | 110GB + ポイント還元 | 7,150円 |

## 各プランの詳細

### ahamo（基本プラン）

| 項目 | 内容 |
|------|------|
| データ容量 | 30GB |
| 月額料金 | 2,970円（税込） |
| 国内通話 | 5分以内無料（標準付帯） |

### ahamo大盛り

| 項目 | 内容 |
|------|------|
| データ容量 | 110GB（基本30GB + 大盛りオプション80GB） |
| 月額料金 | 4,950円（税込） |
| 内訳 | 基本料金2,970円 + 大盛りオプション1,980円 |
| 国内通話 | 5分以内無料（標準付帯） |

### ahamoポイ活

| 項目 | 内容 |
|------|------|
| データ容量 | 110GB |
| 月額料金 | 7,150円（税込） |
| 内訳 | 基本料金2,970円 + 大盛りオプション1,980円 + ポイ活オプション2,200円 |
| 前提条件 | 大盛りオプション加入が必須 |
| ポイント還元 | dカード / d払いで最大+10%還元 |
| ポイント上限 | 4,000ポイント/月 |
| 実質料金目安 | 約2,750円/月（ポイント充当時） |

## 通話料・通話オプション

| 項目 | 料金（税込） |
|------|-------------|
| 国内通話（5分以内） | 無料（標準付帯） |
| 国内通話（5分超過分） | 22円/30秒 |
| かけ放題オプション | 1,100円/月 |

## 海外利用

| 項目 | 内容 |
|------|------|
| 海外データ通信 | 20GBまで追加料金なし |
| 利用可能期間 | 15日間 |

## 割引に関する注意事項

| 割引名 | 適用可否 |
|--------|---------|
| みんなドコモ割 | **対象外** |
| ドコモ光セット割 | **対象外** |
| home 5G セット割 | **対象外** |
| dカードお支払割 | **対象外** |
| ドコモでんきセット割 | **対象外** |

## その他の注意事項

- オンライン専用プランのため、申し込み・各種手続きはWebまたはアプリから行う
- ドコモショップでの対面サポートは原則対象外
- キャリアメール（@docomo.ne.jp）は標準では利用不可（ドコモメール持ち運びオプションで利用可能）
- 家族間通話無料は適用されない
