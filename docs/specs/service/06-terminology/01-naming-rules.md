# カエドキPG 表記ルール

## 問題の背景

要件・仕様書内で「カエドキPG（通常/プラス）」と「カエドキPG」の記載が混在しており、「カエドキPG」が「カエドキPG（通常）」を指すのか「カエドキPG（通常/プラス）両方」を指すのかが曖昧。

## 公式ドキュメントでの表記

### ドコモ公式の正式名称

| 表記 | 対象 |
|------|------|
| いつでもカエドキプログラム | 通常版のみ |
| いつでもカエドキプログラム＋ | プラス版のみ |
| いつでもカエドキプログラム（プラス対象機種） | プラス対象機種での購入プログラム分類 |

### ドコモ公式での略称

| 略称 | 使用場面 |
|------|---------|
| 本プログラム | 提供条件書内での自己参照（最も頻出） |
| PG | 「PG早期ご利用料金」など料金名称の一部としてのみ |

> **「カエドキPG」はドコモ公式ドキュメントには存在しない非公式略称。**

## 推奨表記ルール

プロジェクト内での混乱を防ぐため、以下の表記ルールを推奨する。

### 基本ルール

| 記載したい対象 | 推奨表記 | NG表記 |
|--------------|---------|--------|
| 通常版のみ | カエドキPG（通常） | カエドキPG |
| プラス版のみ | カエドキPG（プラス） | カエドキPG+ |
| 両方を指す場合 | カエドキPG（通常/プラス） | カエドキPG |
| 総称として | カエドキプログラム | カエドキPG |

### 核心ルール

**「カエドキPG」と単独で記載しない。必ず（通常）（プラス）（通常/プラス）のいずれかを付与する。**
