# ドコモでんきセット割

ドコモでんきの契約により、スマートフォンの月額料金から割引されるサービス。2025年6月に新設。

## 割引額

| 対象プラン | 割引額（税込/月） |
|---|---|
| ドコモMAX | -110円 |
| ポイ活MAX | -110円 |
| ポイ活20 | -110円 |
| ドコモmini | -110円 |

**全対象プラン一律 -110円/月**

## 適用条件

- 同一ファミリー割引グループ内にドコモでんきのペア回線が存在すること
- 最大20回線まで適用可能

## 対象外プラン

- 上記の新料金プラン以外（eximo、irumo、旧プラン等は対象外）
- ahamo

## 併用可否

| 割引名 | 併用 |
|---|---|
| ドコモ光セット割 | 可 |
| home 5Gセット割 | 可 |
| みんなドコモ割 | 可 |
| dカードお支払割 | 可 |
| 長期利用割 | 可 |

すべての主要割引と併用可能。

## 注意事項

- 2025年6月新設の割引サービスであるため、それ以前の料金シミュレーションには含まれていない場合がある
- ファミリー割引グループ単位での適用となるため、グループ内にドコモでんきの契約があればグループ内の対象プラン全回線に割引が適用される
- 割引額は小さい（-110円）が、他の割引とすべて併用可能なため、最大割引額の積み上げに寄与する
