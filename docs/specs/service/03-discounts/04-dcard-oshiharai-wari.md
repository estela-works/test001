# dカードお支払割

dカード（家族カード含む）での支払い設定により、月額料金から割引されるサービス。

## 割引額

### 新料金プラン

| 対象プラン | dカード PLATINUM / GOLD / GOLD U | dカード（通常） |
|---|---|---|
| ドコモMAX | -550円 | -220円 |
| ポイ活MAX | -550円 | -220円 |
| ポイ活20 | -550円 | -220円 |
| ドコモmini | -550円 | -220円 |

### 旧料金プラン

| 対象プラン | dカード（種別問わず） |
|---|---|
| eximo | -187円 |
| irumo（3GB / 6GB / 9GB） | -187円 |
| 5Gギガホ プレミア | -187円 |
| ギガホ プレミア | -187円 |
| 5Gギガライト / ギガライト | -187円 |

## 適用条件

- 各利用月の**末日時点**で dカード（家族カード含む）による支払いが設定されていること
- dカード PLATINUM / GOLD / GOLD U の場合は上位の割引額が適用（新プランのみ差あり）

## 対象外プラン

- ahamo
- irumo（0.5GB）
- 定期契約ありのプラン

## 併用可否

| 割引名 | 併用 |
|---|---|
| ドコモ光セット割 | 可 |
| home 5Gセット割 | 可 |
| みんなドコモ割 | 可 |
| ドコモでんきセット割 | 可 |
| 長期利用割 | 可 |

## 注意事項

- 月末時点での支払い設定で判定されるため、月途中での設定変更に注意
- 家族カードでの支払いも対象となる
- 新プランでは dカードのグレード（PLATINUM/GOLD/GOLD U vs 通常）により割引額が異なる
- 旧プランでは dカードの種別にかかわらず一律 -187円
- 定期契約ありのプランは対象外（定期契約なしプランで適用可能）
