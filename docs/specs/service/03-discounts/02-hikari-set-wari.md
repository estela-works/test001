# ドコモ光セット割

ドコモ光とドコモスマートフォンをセットで利用することで、スマートフォン側の月額料金から永年割引されるサービス。

## 割引額

### 新料金プラン

| 対象プラン | 割引額（税込/月） |
|---|---|
| ドコモMAX | -1,210円 |
| ポイ活MAX | -1,210円 |
| ポイ活20 | -1,210円 |
| ドコモmini | -1,210円 |
| eximo | -1,100円 |
| irumo（9GB） | -1,100円 |
| irumo（6GB） | -1,100円 |
| irumo（3GB） | -1,100円 |

### 旧料金プラン

| 対象プラン | 割引額（税込/月） |
|---|---|
| 5Gギガホ プレミア | -1,100円 |
| ギガホ プレミア | -1,100円 |
| 5Gギガライト / ギガライト（3GB超～7GB） | -550円 |
| 5Gギガライト / ギガライト（1GB超～3GB） | -550円 |

## 適用条件

- ドコモ光（定期契約）を契約していること
- 同一ファミリー割引グループに属していること（三親等以内、最大20回線）
- **申込不要**（条件を満たした場合に自動適用）
- 永年割引（契約期間中ずっと適用）

## 対象外プラン

- ahamo
- irumo（0.5GB）
- 5Gギガライト / ギガライト で当月利用量が1GB以下の月

## 併用可否

| 割引名 | 併用 |
|---|---|
| home 5Gセット割 | 不可（ドコモ光セット割が優先） |
| みんなドコモ割 | 可 |
| dカードお支払割 | 可 |
| ドコモでんきセット割 | 可 |
| 長期利用割 | 可 |

## 注意事項

- ドコモ光と home 5G の両方を契約している場合、**ドコモ光セット割が優先**適用され、home 5Gセット割は適用されない
- ファミリー割引グループ内の対象回線すべてに割引が適用される
- ドコモ光の契約を解約した場合、翌月から割引が終了する
