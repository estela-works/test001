# 長期利用割

ドコモの長期利用年数に応じて月額料金から割引されるサービス。新設の割引。

## 割引額

| 利用年数 | 割引額（税込/月） |
|---|---|
| 20年以上 | -220円 |
| 10年以上20年未満 | -110円 |
| 10年未満 | 対象外 |

## 対象プラン

| プラン | 対象 |
|---|---|
| ドコモMAX | 対象 |
| ポイ活MAX | 対象 |
| ポイ活20 | 対象外 |
| ドコモmini | 対象外 |
| eximo | 対象外 |
| irumo | 対象外 |
| ahamo | 対象外 |
| 旧プラン | 対象外 |

**ドコモMAX / ポイ活MAX のみ対象**

## 適用条件

- ドコモの契約期間が10年以上であること
- 対象プラン（ドコモMAX / ポイ活MAX）を利用中であること

## 対象外プラン

- ポイ活20
- ドコモmini
- eximo
- irumo（全容量）
- ahamo
- 旧料金プラン全般

## 併用可否

| 割引名 | 併用 |
|---|---|
| ドコモ光セット割 | 可 |
| home 5Gセット割 | 可 |
| みんなドコモ割 | 可 |
| dカードお支払割 | 可 |
| ドコモでんきセット割 | 可 |

すべての主要割引と併用可能。

## 注意事項

- 対象プランが限定的（ドコモMAX / ポイ活MAX のみ）であるため、適用される利用者は限られる
- 利用年数はドコモの契約継続年数で判定される
- プラン変更により対象外プランに移行した場合、割引は終了する
