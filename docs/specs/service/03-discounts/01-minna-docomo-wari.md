# みんなドコモ割

ファミリー割引グループ内の回線数に応じて、各回線の月額料金から割引されるサービス。

## 割引額

### 新料金プラン

| 対象プラン | 2回線 | 3回線以上 |
|---|---|---|
| ドコモMAX | -550円 | -1,210円 |
| ポイ活MAX | -550円 | -1,210円 |
| ポイ活20 | -550円 | -1,210円 |
| ドコモmini | 割引対象外 | 割引対象外 |

### 旧料金プラン

| 対象プラン | 2回線 | 3回線以上 |
|---|---|---|
| eximo | -550円 | -1,100円 |
| 5Gギガホ プレミア | -550円 | -1,100円 |
| ギガホ プレミア | -550円 | -1,100円 |
| 5Gギガライト / ギガライト | -550円 | -1,100円 |

## 回線カウントルール

| プラン / 契約 | カウント対象 | 割引対象 |
|---|---|---|
| ドコモMAX / ポイ活MAX / ポイ活20 | 対象 | 対象 |
| ドコモmini | **対象** | **対象外** |
| ahamo | **対象** | **対象外** |
| eximo 等旧プラン | 対象 | 対象 |
| 2in1 | 対象外 | 対象外 |
| キッズケータイプラス / プラン | 対象外 | 対象外 |
| irumo（0.5GB） | 対象外 | 対象外 |

**ポイント**: ドコモmini と ahamo は割引自体は受けられないが、グループ内の回線数としてはカウントされる。

## 適用条件

- ファミリー割引グループに2回線以上が属していること
- 回線数のカウントはカウント対象プランのみ

## 対象外プラン

- ドコモmini（カウント対象だが割引対象外）
- ahamo（カウント対象だが割引対象外）
- 2in1（カウント対象外）
- キッズケータイプラス / キッズケータイプラン（カウント対象外）
- irumo（0.5GB）（カウント対象外）

## 併用可否

| 割引名 | 併用 |
|---|---|
| ドコモ光セット割 | 可 |
| home 5Gセット割 | 可 |
| dカードお支払割 | 可 |
| ドコモでんきセット割 | 可 |
| ハーティ割引 | 可 |
| 長期利用割 | 可 |
| ずっとはじめてスマホ割 | **不可** |
| 子育てサポート割引 | **不可** |

## 注意事項

- 回線数の増減により割引額が変動する（例: 3回線から2回線に減った場合、割引額が減少する）
- ドコモmini や ahamo を含めてカウントされるため、これらのプランが多いグループでも3回線以上のカウントに寄与する
- ずっとはじめてスマホ割、子育てサポート割引とは併用不可
