# 割引併用ルール・最大割引シミュレーション

各セット割引の併用可否ルールと、主要プランにおける最大割引額のシミュレーション。

## 併用可否マトリックス

| | ドコモ光セット割 | home 5Gセット割 | みんなドコモ割 | dカードお支払割 | ドコモでんきセット割 | 長期利用割 |
|---|---|---|---|---|---|---|
| **ドコモ光セット割** | - | 不可 | 可 | 可 | 可 | 可 |
| **home 5Gセット割** | 不可 | - | 可 | 可 | 可 | 可 |
| **みんなドコモ割** | 可 | 可 | - | 可 | 可 | 可 |
| **dカードお支払割** | 可 | 可 | 可 | - | 可 | 可 |
| **ドコモでんきセット割** | 可 | 可 | 可 | 可 | - | 可 |
| **長期利用割** | 可 | 可 | 可 | 可 | 可 | - |

### 併用不可の組み合わせ

- **ドコモ光セット割 と home 5Gセット割**: 両方契約がある場合、ドコモ光セット割が優先適用される
- **みんなドコモ割 と ずっとはじめてスマホ割**: 併用不可
- **みんなドコモ割 と 子育てサポート割引**: 併用不可

## 注意事項

- 上記シミュレーションは税込価格で記載
- 基本料金はプランの標準的な月額を記載しており、利用状況や契約内容により異なる場合がある
- ドコモ光セット割と home 5Gセット割は同額のため、シミュレーション結果はどちらを適用しても同一（旧プランの一部を除く）
- 各割引の適用条件を個別に満たす必要がある
