# サービス仕様

ドコモ携帯料金見積もりアプリのベースとなるサービス仕様を整理したドキュメント群。
携帯料金プラン、セット割引、電気・ガス・ネット回線、端末購入プログラム、アクセサリーを網羅する。

## 採番の考え方

| # | フォルダ | 理由 |
|---|---------|------|
| 01 | plans | 見積もりの起点。まず料金プランを決める |
| 02 | infrastructure | プランの次にインフラサービス（光/でんき/ガス）を選ぶ |
| 03 | discounts | プラン＋インフラの組み合わせで割引が決まる |
| 04 | devices | 端末選択・購入プログラム |
| 05 | accessories | 端末に付随するアクセサリー |
| 06 | terminology | 全体の用語定義（参照用） |

## カテゴリ別概要

### 01 料金プラン（[01-plans/](./01-plans/)）

2025年6月5日よりeximo/irumoの新規受付が終了し、新プラン体系に移行。

| プラン | データ容量 | 基本月額（税込） | 割引後最安 |
|--------|-----------|-----------------|-----------|
| ドコモ MAX | 無制限 | 8,448円 | 5,148円 |
| ドコモ ポイ活 MAX | 無制限 | 11,748円 | 実質2,948円 |
| ドコモ ポイ活 20 | 20GB/無制限 | 7,898円～ | - |
| ドコモ mini | 4GB/10GB | 2,750円～ | 880円 |
| ahamo | 30GB | 2,970円 | 2,970円 |
| ahamo 大盛り | 110GB | 4,950円 | 4,950円 |

### 02 インフラサービス（[02-infrastructure/](./02-infrastructure/)）

| サービス | 月額（税込） | 主な特典 |
|---------|------------|---------|
| ドコモ光（1ギガ） | 4,400円～5,720円 | セット割、工事費無料 |
| home 5G | 4,950円 | セット割、端末実質0円 |
| ドコモでんき | 地域電力と同額～+500円 | dポイント最大20%還元 |
| ドコモガス | 地域ガスと同額 | dポイント最大1%還元 |

### 03 セット割引（[03-discounts/](./03-discounts/)）

| 割引名 | 最大割引額（税込/月） |
|--------|---------------------|
| みんなドコモ割（3回線以上） | 1,210円 |
| ドコモ光セット割 / home 5Gセット割 | 1,210円 |
| dカードお支払割（PLATINUM/GOLD/GOLD U） | 550円 |
| ドコモでんきセット割 | 110円 |
| 長期利用割（20年以上） | 220円 |
| **ドコモ MAX 合計最大** | **3,300円** |

### 04 端末・補償（[04-devices/](./04-devices/)）

| プログラム | 概要 |
|-----------|------|
| カエドキプログラム（通常） | 残価設定型24回払い、23か月目返却で残価免除 |
| カエドキプログラム＋ | 12か月目以降返却可、smartあんしん補償必須 |
| smartあんしん補償 | 端末補償サービス（月額330円～1,720円） |
| 端末購入割引 | 5G WELCOME割（最大44,000円）ほか |

### 05 アクセサリー（[05-accessories/](./05-accessories/)）

docomo selectのアクセサリー全20カテゴリと見積もり時の分類（必須級/推奨/オプション）。

### 06 用語・表記ルール（[06-terminology/](./06-terminology/)）

プロジェクト内の用語定義、公式名称との対応表、表記ルール。
